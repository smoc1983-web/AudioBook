# Audiobook после сверки с Nova 3.0.2g

[Публичное описание релиза](https://github.com/SroedingerS/AudiobooksNova-Releases/releases/tag/v3.0.2g) использовано как источник сценариев. Целевая платформа Android, проект Audiobook и его дизайн. Для сравнения используется собственная версия Preview 4.2.99.

| Экран | Сценарий | Важные состояния |
| --- | --- | --- |
| Книги | Найти начатую книгу или открыть свою полку | Библиотека пуста, книга закончена, полка удалена |
| Каталог | Скрыть завершённые аудиоиздания | Каталог офлайн, другая озвучка того же названия |
| Плеер | Настроить вспомогательные действия и время главы | Скрыты все действия, сброс, крупный шрифт |
| Виджет | Понять, сколько слушать, открыть последнюю книгу | Нет длительности, пауза, холодный процесс, локальная глава |
| Меню книги | Найти ту же озвучку на другом источнике | Неизвестен чтец, одноимённая книга, пустая выдача |
| Карточка Audiokniga.life | Показать обложку книги | Адаптивное изображение, заглушка, чужая рекомендация |

Холодное открытие уже восстанавливает книгу на паузе. Сервис предпочитает подтверждённые скачанные главы, поэтому для сохранения поведения используются существующие точки входа. 101.ru и читалка отсутствуют как подсистемы. Для исправления служебных записей Audio-Lib и Lis10book нужны воспроизводимые примеры. По одному описанию релиза нельзя отличить такую запись от обычной главы.
