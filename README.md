# Audiobook 4.2 — приложение и рабочие материалы

Актуальная сборка: **4.2-preview.48 — Предание.ру и обновления без входа в GitHub**, отдельный пакет `com.audiobookdownloader.preview`. Стабильная Audiobook остаётся установленной независимо. Настройки и загрузки Preview изолированы; папка — `Download/AudioBooks-Preview`. В настройках доступны три действия: проверка, загрузка и установка обновления из отдельного HTTPS-канала без входа в GitHub.


**Основной канал дальнейших обновлений — Preview.** По решению владельца устанавливаем её рядом со старой Audiobook и явно подключаем папку старых книг через системный выбор Android. Все следующие обновления ставятся поверх Preview с сохранением её данных. [Простая инструкция перехода](docs/PREVIEW-AS-MAIN.md).

Добавлен четырнадцатый источник [Предание.ру](https://predanie.ru/audio/): аудиопоиск, категории и главы с длительностью для общего плеера и загрузчика. При обновлении источник добавляется к сохранённому набору один раз; последующее отключение сохраняется. Проверены реальный запрос «Гоголь», 162 уникальные главы «Пирамиды» и доступность MP3. [Источник и прямые обновления](docs/PREDANIE-AND-DIRECT-UPDATES.md).

Добавлены уведомления о новых подтверждённых продолжениях книг в коллекциях: фоновая проверка примерно раз в 12 часов, ручная проверка, список новинок и причины недоступности отдельных циклов. Первая успешная проверка запоминает уже опубликованные книги без уведомлений. Управление — «Настройки → Продолжения» или кнопка в коллекциях; сайт должен предоставлять полный список цикла. [Описание функции и ограничений](docs/CONTINUATION-NOTIFICATIONS.md).

Исправлены метаданные плеера в шторке, общий кеш обложек для онлайн-книг и загрузочный индикатор после ошибки. В настройках и меню Android появились полноценные макеты трёх виджетов. Проверены 27 сочетаний размеров и тем.

Онлайн-плеер уточняет длительности глав в фоне и считает остаток книги с учётом скорости; поддержаны смешанные онлайн/скачанные главы. Общий поиск использует два независимых задания: медленный или недоступный сайт не блокирует найденные книги. Контрольный пример — «Сыны грома» на Bookinfo, 30 глав без длительностей на странице.

Для подключения скачанных книг откройте Preview → «Книги» → «Синхронизация библиотеки» → «Выбрать папку библиотеки» и выберите `Download/AudioBooks`. Новые загрузки остаются в `Download/AudioBooks-Preview`. Старая Audiobook сохраняет свои настройки, коллекции и позиции; они автоматически не переносятся. Подпись, package и каталог Preview при следующих выпусках сохраняются. Исходный ключ старой стабильной установки для этого режима не требуется.

Репозиторий теперь содержит полный Gradle-проект и сохранённую историю. К прежним четырём источникам (Азбука веры, Книгоблуд, Bookinfo и Audiokniga-online.ru) оставлены девять дополнительных со скриншотов, добавлен Предание.ру — всего 14. Общий поиск использует включённые переключателями сайты, либо можно выбрать один. Lis10Book, Слушкин Всем и Audioboo удалены по запросу пользователя; оставшиеся источники и настройки выбора сохранены. Каталоги и форматы данных проверены отдельно от полного воспроизведения на телефоне. LibriVox и Internet Archive исключены из активного каталога. Между разделами добавлена цилиндрическая деформация настоящего изображения страницы по принципу android-pagecurl, следующая за пальцем при горизонтальном свайпе. В плеере появилась кнопка «В коллекцию», переработано продление таймера встряхиванием, новый адаптивный ярлык содержит полумесяц, Play и открытую книгу.

## Структура

- current/ — канонические Kotlin-экран и PlaybackService, общие Java-классы, темы, жанры и виджеты.
- app/ — восстановленная сборочная конфигурация, нативный каталог и рабочая совместимость старого виджета.
- history/, design/, references/, releases/ — прежние снимки, макеты, отчёты и архивы, сохранённые отдельно от музыкального проекта.

## Проверки и сборка

Нужны JDK 17, Gradle 8.9 и Android SDK 36.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

В GitHub Actions выполняются 170 сценариев обработчиков на DOM-фикстурах, 69 JVM-тестов для каждого канала (ещё один необязательный пропущен), аудит доступности 14 сайтов и восемь инструментальных проверок Android 36. Публикация APK допускается только после успешного запуска на Android. Аудит HTTP не подтверждает скачивание/воспроизведение; LiveCatalogTest относится только к необязательной совместимости старых архивных изданий (RUN_SAVED_ARCHIVE_COMPATIBILITY=1).

Первую Preview устанавливают отдельно, затем обновляют через «Настройки → Обновления Preview». Подключение GitHub не требуется. Описание версии и проверенные части APK доступны в [канале обновлений](https://audiobook-smoc1983-updates.amplecoot2048.chatgpt.site). Стабильный канал заработает после публикации APK, подписанного исходным ключом на телефоне владельца; неподписанные кандидаты не предлагаются для установки. Android запрашивает согласие на установку APK. Ключ стабильной версии не нужен: у Preview собственная сохраняемая подпись. Инструкция по постоянному резервированию ключа — в PREVIEW-UPDATES.md.

## GitHub и резервные копии

Рабочие материалы сохранены в закрытом репозитории
[smoc1983-web/AudioBook](https://github.com/smoc1983-web/AudioBook), актуальная ветка `main`; исходная рабочая ветка `integration/verified-sources` сохранена в истории.
Сохранённые версии в history/ — реальные снимки файлов, а не восстановленная
Git-история первоначальных авторов.

```sh
git clone --branch main https://github.com/smoc1983-web/AudioBook.git
cd AudioBook
```

Все исходники, изображения и ресурсы текущей версии хранятся обычными файлами.
Только три больших исторических ZIP-архива в releases/ разделены на части
из-за ограничения загрузки через подключение. Все их байты сохранены в
`releases/.parts/`. Чтобы собрать эти архивы после скачивания репозитория:

```sh
python tools/restore_archives.py
```

Скрипт проверяет SHA-256 каждой части и готового архива. Совпадающие готовые
файлы пропускаются; существующие файлы с другим содержимым сохраняются.
Сборка архивов не требуется для работы с current/ и запуска проверок.

`FILES.json` содержит контрольные суммы файлов репозитория, кроме самого
манифеста. `docs/ORIGINAL-FILES.json` — манифест первоначального сохранения,
а `releases/ARCHIVE-PARTS.json` описывает восстановление трёх больших архивов.
Первоначальная полная Git-копия также сохранена отдельно в рабочей среде:
`/workspace/Audiobook-Workspace.bundle`.
