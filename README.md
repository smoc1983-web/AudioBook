# Audiobook Preview 4.2 — отдельное приложение и рабочие материалы

Актуальная сборка: **4.2-preview.27 — цилиндрическое перелистывание и полумесяц**, отдельный пакет `com.audiobookdownloader.preview`. Стабильная Audiobook остаётся установленной независимо. Настройки и загрузки Preview изолированы; папка — `Download/AudioBooks-Preview`. В настройках Preview доступны проверка, загрузка и установка обновлений из закрытого GitHub.

Репозиторий теперь содержит полный Gradle-проект и сохранённую историю. По последнему запросу восстановлены четыре источника: Азбука веры, Книгоблуд, Bookinfo и Audiokniga-online.ru. Доступен общий поиск или поиск на одном сайте. LibriVox и Internet Archive исключены из активного каталога. Между разделами добавлена цилиндрическая деформация настоящего изображения страницы по принципу android-pagecurl, следующая за пальцем при горизонтальном свайпе. В плеере появилась кнопка «В коллекцию», переработано продление таймера встряхиванием, новый адаптивный ярлык содержит полумесяц, Play и открытую книгу.

## Структура

- current/ — канонические Kotlin-экран и PlaybackService, общие Java-классы, темы, жанры и виджеты.
- app/ — восстановленная сборочная конфигурация, нативный каталог и рабочая совместимость старого виджета.
- history/, design/, references/, releases/ — прежние снимки, макеты, отчёты и архивы, сохранённые отдельно от музыкального проекта.

## Проверки и сборка

Нужны JDK 17, Gradle 8.9 и Android SDK 36.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

В GitHub Actions выполняются 120 сценариев обработчиков на DOM-фикстурах, JVM-тесты, аудит доступности четырёх сайтов и инструментальная проверка Android 36. Публикация APK допускается только после успешного запуска на Android. Аудит HTTP не подтверждает скачивание/воспроизведение; LiveCatalogTest относится только к необязательной совместимости старых архивных изданий (RUN_SAVED_ARCHIVE_COMPATIBILITY=1).

Первую Preview устанавливают отдельно, затем обновляют через «Настройки → Обновления Preview». Для закрытого репозитория требуется одноразовое подключение GitHub в самом приложении (Contents: Read-only). Android запрашивает согласие на установку APK. Ключ стабильной версии не нужен: у Preview собственная сохраняемая подпись. Инструкция по постоянному резервированию ключа — в PREVIEW-UPDATES.md.

## GitHub и резервные копии

Рабочие материалы сохранены в закрытом репозитории
[smoc1983-web/AudioBook](https://github.com/smoc1983-web/AudioBook), актуальная ветка `main`; исходная рабочая ветка `integration/verified-sources` сохранена в истории.
Сохранённые версии в history/ — реальные снимки файлов, а не восстановленная
Git-история первоначальных авторов.

```sh
git clone --branch main https://github.com/smoc1983-web/AudioBook.git
cd AudioBook
```

Все исходники, изображения и ресурсы текущей версии хранятся обычными файлами.
Только три больших исторических ZIP-архива в releases/ разделены на части
из-за ограничения загрузки через подключение. Все их байты сохранены в
`releases/.parts/`. Чтобы собрать эти архивы после скачивания репозитория:

```sh
python tools/restore_archives.py
```

Скрипт проверяет SHA-256 каждой части и готового архива. Совпадающие готовые
файлы пропускаются; существующие файлы с другим содержимым сохраняются.
Сборка архивов не требуется для работы с current/ и запуска проверок.

`FILES.json` содержит контрольные суммы файлов репозитория, кроме самого
манифеста. `docs/ORIGINAL-FILES.json` — манифест первоначального сохранения,
а `releases/ARCHIVE-PARTS.json` описывает восстановление трёх больших архивов.
Первоначальная полная Git-копия также сохранена отдельно в рабочей среде:
`/workspace/Audiobook-Workspace.bundle`.
