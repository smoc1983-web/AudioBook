# Audiobook — рабочие материалы

Актуальная ревизия: **4.0-search-modes-1**. Начинайте работу с папки **current/**.
В ней объединены последние изменения. Папка history/ содержит предыдущие
снимки; они нужны для истории и проверок, а не для установки поверх current/.

## Что сохранено

| Папка | Содержимое |
| --- | --- |
| current/ | Последние Kotlin/Java-исходники, ресурсы Android и проверки |
| history/ | 47 предыдущих рабочих каталогов с исходниками и заметками |
| design/generated/ | Все доступные сгенерированные фоны, макеты и аватары |
| references/ | Доступные исходные вложения и диагностические отчёты |
| releases/ | Ранее выданные ZIP-архивы, включая последние небольшие части |
| docs/ | Инструкция продолжения, изменения, публикация для Telegram и результаты проверок |
| scripts/previous/ | Скрипты, использованные для предыдущих изменений |
| tools/ | Запуск проверок после переноса на другой компьютер |

## Продолжить разработку

1. Прочитайте [HANDOFF.md](docs/HANDOFF.md).
2. Для переноса в существующий Android-проект используйте
   [INSTALL.md](docs/INSTALL.md).
3. Из корня этой папки запустите `python tools/run_checks.py`.
   Нужны Python 3 с Pillow, Node.js и JDK 11 или новее.
4. Android-сборку выполняйте в вашем исходном проекте командой
   `:app:assembleDebug`.

Это сохранённый комплект разработки, **не полный Gradle-проект и не APK**.
Полные Gradle-файлы, основной AndroidManifest.xml, старый AudioBookWidget.kt
и ключ подписи в эту беседу не передавались. Их нужно сохранить из вашего
Android-проекта. Не создавайте вместо них пустые файлы.

Прикладные файлы последней версии скопированы без изменения. В текущих
проверках абсолютные пути `/workspace/...` заменены на ссылки на history/;
они запускаются из этой папки и после её переноса.

## GitHub и резервные копии

Рабочие материалы сохранены в закрытом репозитории
[smoc1983-web/AudioBook](https://github.com/smoc1983-web/AudioBook), ветка `main`.
Сохранённые версии в history/ — реальные снимки файлов, а не восстановленная
Git-история первоначальных авторов.

```sh
git clone https://github.com/smoc1983-web/AudioBook.git
cd AudioBook
```

Все исходники, изображения и ресурсы текущей версии хранятся обычными файлами.
Только три больших исторических ZIP-архива в releases/ разделены на части
из-за ограничения загрузки через подключение. Все их байты сохранены в
`releases/.parts/`. Чтобы собрать эти архивы после скачивания репозитория:

```sh
python tools/restore_archives.py
```

Скрипт проверяет SHA-256 каждой части и готового архива. Совпадающие готовые
файлы пропускаются; существующие файлы с другим содержимым сохраняются.
Сборка архивов не требуется для работы с current/ и запуска проверок.

`FILES.json` содержит контрольные суммы файлов репозитория, кроме самого
манифеста. `docs/ORIGINAL-FILES.json` — манифест первоначального сохранения,
а `releases/ARCHIVE-PARTS.json` описывает восстановление трёх больших архивов.
Первоначальная полная Git-копия также сохранена отдельно в рабочей среде:
`/workspace/Audiobook-Workspace.bundle`.
