# Audiobook 4.2 — приложение и рабочие материалы

Актуальная сборка: **4.2.73 — продолжения серий прямо в коллекции и понятные меню, подписанная release-сборка**, отдельный пакет `com.audiobookdownloader.preview`. Стабильная Audiobook остаётся установленной независимо. Настройки и загрузки Preview изолированы; папка — `Download/AudioBooks-Preview`. В настройках доступны три действия: проверка, загрузка и установка обновления из отдельного HTTPS-канала без входа в GitHub.


В плеере → «Серия» и в настройках продолжений доступен официальный каталог Литрес / Author.Today: фильтры текста и аудио, номера томов, даты проверки, статусы публикации и ссылки на площадки. Текстовые уведомления включаются отдельно, первая сверка тихая. Ошибки сохраняют прежний список; неполные и противоречивые сведения не создают оповещений. [Как устроено и что проверено](docs/TEXT-SERIES-CATALOG.md).

Оптимизирована прокрутка больших результатов поиска: подготовка серий и индекса скачанных книг выполняется в фоне, снимок повторно используется при обновлениях плеера. Новые обложки ждут остановки прокрутки, кэш блокировок ограничен. Обычный скроллинг больше не записывает весь экран в слой для перелистывания. Проверены 600 карточек и сохранение позиции; реальное обновление с 4.2.63 сохраняет данные. [Изменения и пределы проверки](docs/SEARCH-SCROLL-PERFORMANCE.md).

Исправлены ложные названия серий из ссылок на соседние книги. Сверка Author.Today / Литрес отделяет прямой цикл от большого мира: «Золото мертвых» — «Хранитель кладов», том 2; родительский «Отдел 15-К» показывается отдельно. В плеере → «Серия» доступны скачанные тома, сведения о цикле, сверка и управление отслеживанием. Для старых записей восстанавливается адрес из метаданных или точного поиска по названию и автору; явно указанный цикл «Отеля Перекресток» с двумя томами распознаётся и без совпадения в независимом справочнике.

Уже вышедшие книги показаны отдельно от новых уведомлений. Начальная проверка запоминает их без оповещений; последующие проверки сообщают о подтверждённом новом аудио. В настройках продолжений добавлена отдельная подписка на новинки аудиокниг Литрес (по умолчанию выключена): проверяются аудиоформат, автор, название и дата выхода. Ссылки Литрес открываются на официальном сайте. После обновления один раз показывается окно «Что нового», повторный просмотр — в настройках. [Реализация, ограничения и проверки](docs/SERIES-VERIFICATION.md).

Исправлена передача загруженного APK установщику: FileProvider теперь открывает фактическую папку загрузки, ошибка запуска не заменяется сообщением «APK проверен». Проверено реальное окно Android с кнопкой обновления. Для перехода с прежних 48–53 первый APK необходимо открыть через «Мои файлы»; удаление и очистка данных не нужны. [Короткая инструкция и диагностика](docs/INSTALLER-PATH-FIX.md).

После сообщения о блокировке Play Protect из устанавливаемого APK удалены служба чтения экранов, Shizuku, связанный код и разрешения. Публикуется release без режима отладки с прежними applicationId и сертификатом. Это проверка состава APK, не одобрение Google: её решение на конкретных телефонах необходимо подтвердить отдельно. [Причина изменения и ограничения проверки](docs/PLAY-PROTECT.md).

Перенос коллекций теперь выполняется через выбранный пользователем JSON/XML-файл: предварительная проверка, подтверждение, объединение без дубликатов, копия перед импортом и отмена. Уже сохранённые полки и книги не удаляются. Без файла резервной копии закрытые коллекции другой версии автоматически не читаются. [Инструкция](docs/COLLECTION-TRANSFER.md).

**Отображаемое имя основного приложения теперь Audiobook.** Пакет и подпись прежней Preview сохранены; обновление устанавливается поверх неё. [Проверка обновления 48 → 50](docs/AUDIOBOOK-RENAME-UPDATE.md).

**Технический канал дальнейших обновлений — прежний Preview.** По решению владельца устанавливаем её рядом со старой Audiobook и явно подключаем папку старых книг через системный выбор Android. Все следующие обновления ставятся поверх Preview с сохранением её данных. [Простая инструкция перехода](docs/PREVIEW-AS-MAIN.md).

Добавлен четырнадцатый источник [Предание.ру](https://predanie.ru/audio/): аудиопоиск, категории и главы с длительностью для общего плеера и загрузчика. При обновлении источник добавляется к сохранённому набору один раз; последующее отключение сохраняется. Проверены реальный запрос «Гоголь», 162 уникальные главы «Пирамиды» и доступность MP3. [Источник и прямые обновления](docs/PREDANIE-AND-DIRECT-UPDATES.md).

Добавлены уведомления о новых подтверждённых продолжениях книг в коллекциях: фоновая проверка примерно раз в 12 часов, ручная проверка, список новинок и причины недоступности отдельных циклов. Первая успешная проверка запоминает уже опубликованные книги без уведомлений. Управление — «Настройки → Продолжения» или кнопка в коллекциях; сайт должен предоставлять полный список цикла. [Описание функции и ограничений](docs/CONTINUATION-NOTIFICATIONS.md).

Исправлены метаданные плеера в шторке, общий кеш обложек для онлайн-книг и загрузочный индикатор после ошибки. В настройках и меню Android появились полноценные макеты трёх виджетов. Проверены 27 сочетаний размеров и тем.

Онлайн-плеер уточняет длительности глав в фоне и считает остаток книги с учётом скорости; поддержаны смешанные онлайн/скачанные главы. Общий поиск использует два независимых задания: медленный или недоступный сайт не блокирует найденные книги. Контрольный пример — «Сыны грома» на Bookinfo, 30 глав без длительностей на странице.

Для подключения скачанных книг откройте Preview → «Книги» → «Синхронизация библиотеки» → «Выбрать папку библиотеки» и выберите `Download/AudioBooks`. Новые загрузки остаются в `Download/AudioBooks-Preview`. Старая Audiobook сохраняет свои настройки, коллекции и позиции; они автоматически не переносятся. Подпись, package и каталог Preview при следующих выпусках сохраняются. Исходный ключ старой стабильной установки для этого режима не требуется.

Репозиторий теперь содержит полный Gradle-проект и сохранённую историю. К прежним четырём источникам (Азбука веры, Книгоблуд, Bookinfo и Audiokniga-online.ru) оставлены девять дополнительных со скриншотов, добавлен Предание.ру — всего 14. Общий поиск использует включённые переключателями сайты, либо можно выбрать один. Lis10Book, Слушкин Всем и Audioboo удалены по запросу пользователя; оставшиеся источники и настройки выбора сохранены. Каталоги и форматы данных проверены отдельно от полного воспроизведения на телефоне. LibriVox и Internet Archive исключены из активного каталога. Между разделами добавлена цилиндрическая деформация настоящего изображения страницы по принципу android-pagecurl, следующая за пальцем при горизонтальном свайпе. В плеере появилась кнопка «В коллекцию», переработано продление таймера встряхиванием, новый адаптивный ярлык содержит полумесяц, Play и открытую книгу.

## Структура

- current/ — канонические Kotlin-экран и PlaybackService, общие Java-классы, темы, жанры и виджеты.
- app/ — восстановленная сборочная конфигурация, нативный каталог и рабочая совместимость старого виджета.
- history/, design/, references/, releases/ — прежние снимки, макеты, отчёты и архивы, сохранённые отдельно от музыкального проекта.

## Проверки и сборка

Нужны JDK 17, Gradle 8.9 и Android SDK 36.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

В GitHub Actions выполняется 171 сценарий обработчиков на DOM-фикстурах, 97 JVM-тестов для каждого варианта (ещё один необязательный пропущен), шесть проверок gate разрешений, аудит доступности 14 сайтов и 19 основных инструментальных проверок Android 36. Два opt-in сценария обновления запускаются отдельно: реально установленная предыдущая 4.2.62 принимает новый release APK и открывает системное подтверждение; отдельная замена пакета сохраняет полку, настройки, URI библиотеки, приватный файл и SHA-256 контрольного WAV. Проверяются здоровый запуск release и отсутствие удалённых компонентов. Старые проверки чтения чужих экранов и закрытых данных выведены в архив вместе с соответствующей функциональностью. Публикация APK допускается только после успешного прогона. Проверки AOSP не содержат Google Play Protect и не подтверждают его решение на телефонах. [Данные выпуска 4.2.63](docs/verification/checks-100063.json). Аудит HTTP не доказывает воспроизведение; LiveCatalogTest — необязательная совместимость старых архивов (RUN_SAVED_ARCHIVE_COMPATIBILITY=1).

Первую Preview устанавливают отдельно, затем обновляют через «Настройки → Обновления». Подключение GitHub не требуется. Описание версии и проверенные части APK доступны в [канале обновлений](https://audiobook-smoc1983-updates.amplecoot2048.chatgpt.site). Стабильный канал заработает после публикации APK, подписанного исходным ключом на телефоне владельца; неподписанные кандидаты не предлагаются для установки. Android запрашивает согласие на установку APK. Ключ стабильной версии не нужен: у Preview собственная сохраняемая подпись. Инструкция по постоянному резервированию ключа — в PREVIEW-UPDATES.md.

## GitHub и резервные копии

Рабочие материалы сохранены в закрытом репозитории
[smoc1983-web/AudioBook](https://github.com/smoc1983-web/AudioBook), актуальная ветка `main`; исходная рабочая ветка `integration/verified-sources` сохранена в истории.
Сохранённые версии в history/ — реальные снимки файлов, а не восстановленная
Git-история первоначальных авторов.

```sh
git clone --branch main https://github.com/smoc1983-web/AudioBook.git
cd AudioBook
```

Все исходники, изображения и ресурсы текущей версии хранятся обычными файлами.
Только три больших исторических ZIP-архива в releases/ разделены на части
из-за ограничения загрузки через подключение. Все их байты сохранены в
`releases/.parts/`. Чтобы собрать эти архивы после скачивания репозитория:

```sh
python tools/restore_archives.py
```

Скрипт проверяет SHA-256 каждой части и готового архива. Совпадающие готовые
файлы пропускаются; существующие файлы с другим содержимым сохраняются.
Сборка архивов не требуется для работы с current/ и запуска проверок.

`FILES.json` содержит контрольные суммы файлов репозитория, кроме самого
манифеста. `docs/ORIGINAL-FILES.json` — манифест первоначального сохранения,
а `releases/ARCHIVE-PARTS.json` описывает восстановление трёх больших архивов.
Первоначальная полная Git-копия также сохранена отдельно в рабочей среде:
`/workspace/Audiobook-Workspace.bundle`.
