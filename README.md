# Audiobook 4.1 — приложение и рабочие материалы

Актуальная версия: **4.1-verified-sources-1**. Репозиторий теперь содержит полный Gradle-проект и сохранённую историю. Поиск и загрузка глав используют проверенные HTTP/JSON-каталоги Internet Archive и коллекцию LibriVox; прежние четыре сайта убраны из активного поиска.

- [Проверенная сборка и APK](docs/BUILD-4.1.md)
- [Аудит источников](docs/SOURCE-REPLACEMENT.md)
- [Продолжить разработку](docs/HANDOFF.md)

## Структура

- current/ — канонические Kotlin-экран и PlaybackService, общие Java-классы, темы, жанры и виджеты.
- app/ — восстановленная сборочная конфигурация, нативный каталог и рабочая совместимость старого виджета.
- history/, design/, references/, releases/ — прежние снимки, макеты, отчёты и архивы, сохранённые отдельно от музыкального проекта.

## Проверки и сборка

Нужны JDK 17, Gradle 8.9 и Android SDK 36.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

В GitHub Actions RUN_LIVE_SOURCES=1 включает настоящий поиск, получение MP3, загрузку аудиоданных и офлайн-декодирование ffmpeg. Старые текстовые проверки четырёх веб-сайтов относятся к исторической версии 4.0; они не заменяют новую компиляцию и тесты адаптеров.

Из исходного проекта не предоставлялись ключ подписи и старый AudioBookWidget. Добавлена рабочая совместимость виджета; исходный ключ подписи не подменялся. Для обновления поверх установленной версии нужен прежний ключ. Пользовательские папки, настройки, сохранённые книги и прогресс не удалялись.

## GitHub и резервные копии

Рабочие материалы сохранены в закрытом репозитории
[smoc1983-web/AudioBook](https://github.com/smoc1983-web/AudioBook), ветка `integration/verified-sources` (первоначальный комплект — `main`).
Сохранённые версии в history/ — реальные снимки файлов, а не восстановленная
Git-история первоначальных авторов.

```sh
git clone --branch integration/verified-sources https://github.com/smoc1983-web/AudioBook.git
cd AudioBook
```

Все исходники, изображения и ресурсы текущей версии хранятся обычными файлами.
Только три больших исторических ZIP-архива в releases/ разделены на части
из-за ограничения загрузки через подключение. Все их байты сохранены в
`releases/.parts/`. Чтобы собрать эти архивы после скачивания репозитория:

```sh
python tools/restore_archives.py
```

Скрипт проверяет SHA-256 каждой части и готового архива. Совпадающие готовые
файлы пропускаются; существующие файлы с другим содержимым сохраняются.
Сборка архивов не требуется для работы с current/ и запуска проверок.

`FILES.json` содержит контрольные суммы файлов репозитория, кроме самого
манифеста. `docs/ORIGINAL-FILES.json` — манифест первоначального сохранения,
а `releases/ARCHIVE-PARTS.json` описывает восстановление трёх больших архивов.
Первоначальная полная Git-копия также сохранена отдельно в рабочей среде:
`/workspace/Audiobook-Workspace.bundle`.
