AudioBook 4.0 — подключение Азбуки веры, редакция 4.0-azbyka-1

Установка
Замените app/src/main/java/com/MainActivity.kt файлом из архива.
PlaybackService.kt и AudioBookWidget.kt в этом обновлении менять не требуется.
Запустите :app:assembleDebug в своём проекте и установите полученный APK.
В архиве исходник и инструкция, готового APK нет.
За основу взят последний MainActivity.kt из AudioBook-4.0-diagnostics-2.zip.
Сохранены дизайн 4.0, плеер в сервисе, обложки, синхронизация библиотеки,
серии, единый поиск, свайпы и обработчик диагностических отчётов.

Что добавлено
- Азбука веры — третий источник единого поиска, карточек и домашней подборки.
- Прямые ссылки https://azbyka.ru/audio/<название>.html открываются как книги.
- Каталог читает названия, авторов, обложки и ссылки на следующие страницы.
- Страница книги поддерживает публичные M3U-плейлисты, MP3 и стандартные
  WordPress-плейлисты. Порядок глав берётся из плейлиста; название главы
  содержит порядковый номер, чтобы одинаковые названия не перезаписывались.
- MP3-главы имеют приоритет перед ссылкой на всю книгу в M4B.
- Книги передаются существующему плееру и механизму загрузки.
- Издания объединяются существующим алгоритмом по названию и совместимому
  автору. Ссылки на разные источники сохраняются. Разные тома не объединяются.
- Поисковые браузеры и нативные категории открываются последовательно,
  одновременно проверяются не более двух кандидатов внешнего поиска.

Саморазвитие
Поиск → Саморазвитие открывает общий раздел трёх источников.
Для Азбуки подключена настоящая категория «Психология»:
https://azbyka.ru/audio/metka/psixologiya
Изначально выводятся книги категорий и результаты внешней проверки жанров.
Чтобы искать внутри раздела, введите название или автора и нажмите «Найти».
Выбранный жанр сохраняется; запрос отправляется источникам, затем проверяется
жанровая принадлежность. Текст названия сам по себе не служит доказательством жанра.
«Ещё книги этого жанра» продолжает страницы категорий и внешнюю подборку.
«Повторить поиск жанра» сохраняет введённый запрос.
«На главную» сбрасывает жанр и возвращает обычный поиск.
Весь религиозный каталог Азбуки, молитвы и музыка не отнесены к саморазвитию.

Поиск и ограничения
На сайте Азбуки поиск встроен через Яндекс. Вместо неподтверждённого API
общий текстовый поиск использует публичную выдачу Google с резервом Bing,
ограниченную адресами azbyka.ru/audio. Категория «Психология» читается напрямую
и не зависит от выдачи поисковиков. Текстовый поиск может охватывать только
проиндексированные страницы; при блокировке Google/Bing охват уменьшается.
Книги Книгоблуда и Bookinfo проверяются по категориям сайтов и существующему
классификатору открытых библиографических источников.
Для внешних кандидатов проверяется наличие доступного аудио, а также
совпадение названия/автора при использовании внешних жанровых метаданных.
Поиск ограничен временем и числом проверяемых кандидатов; он не скачивает
целиком каталоги трёх сайтов.
На Азбуке серии читаются только при явных ссылках на серию/цикл.
Каталог автора не выдаётся за цикл; отсутствующий номер тома не придумывается.

Проверка
Выполнена проверка строк и скобок Kotlin, сохранения прежнего opt-in
ExperimentalComposeUiApi, отсутствия плеера MediaPlayer в Activity,
версии и реквизитов, а также неизменности PlaybackService.kt.
42 сценария JavaScript-парсеров прошли: прежние категории/серии, внешние
метаданные/выдача, новые категории Азбуки, авторы/обложки и M3U.
Это синтетические HTML/M3U-фикстуры с реальными проверенными адресами,
а не проверки парсера на выгруженном HTML сайта.
Полного Gradle-проекта, Android SDK и эмулятора в рабочем окружении нет.
assembleDebug не запускался; воспроизведение и загрузка с Азбуки на телефоне
не проверены. Структура сайта или недоступность сети могут потребовать правки.

Проверка на телефоне после сборки
1. Поиск → Саморазвитие: должны появиться карточки «Психологии» Азбуки.
2. В том же разделе введите «Разобраться в себе», затем «Найти».
3. Откройте книгу Азбуки: проверьте автора, обложку, главы и воспроизведение.
4. Проверьте загрузку одной главы и запуск после блокировки телефона.
5. Вернитесь на главную; убедитесь, что обычный поиск охватывает три источника.
При ошибке сборки пришлите текст compileDebugKotlin.
При вылете: шестерёнка → Диагностика → Отчёт о последнем сбое → Скопировать отчёт.
