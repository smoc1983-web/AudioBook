AudioBook 4.0 — поиск и открытие ссылок
Диагностика: 4.0-search-window-1

Замените MainActivity.kt в app/src/main/java/com/MainActivity.kt, затем соберите :app:assembleDebug и установите новый APK.
В архиве только MainActivity.kt и эта инструкция. PlaybackService.kt менять не нужно: предыдущая правка продления таймера встряхиванием сохранена.

Что изменено:
- Скрытые WebView подключены к нативному окну Activity. У них есть полноценный размер страницы, но их содержимое скрыто; они не принадлежат Compose AndroidView и прокручиваемым спискам.
- При закрытии экрана браузеры отменяются, отсоединяются и уничтожаются.
- Открытие ссылки имеет общий тайм-аут 45 секунд, а ожидание ответа JavaScript — 8 секунд. Поздние ответы от старой страницы игнорируются.
- Если документ уже появился, разбор начинается без ожидания зависших рекламных ресурсов. Если главы ещё загружаются, страница проверяется повторно в ограниченном интервале.
- Ошибки сети, HTTP и сертификата при открытии ссылки показываются на экране. Проверки HTTPS не отключаются.
- Поиск Книгоблуда ограничивает ожидание JavaScript; для каждого листа карты Азбуки добавлен предел 25 секунд. Сбой источника позволяет продолжить поиск в других источниках.

Проверено: структура Kotlin, 50 сценариев существующих JavaScript-парсеров на искусственных HTML/JSON, сохранение прежних исправлений работы с файлами на фоне. PlaybackService.kt и код парсеров не изменены.
Полный Android-проект и SDK недоступны: assembleDebug не запускался. Саму указанную ссылку и работу WebView на телефоне здесь проверить не удалось.

Проверка на телефоне:
1. Вставить https://mob.knigoblud.club/c0b3325b-f922-4ae2-bfc0-9eb9acc5ab09 и нажать «Найти».
2. Проверить обычный поиск по названию на всех трёх источниках.
3. Во время поиска вернуться на главную и начать другой запрос: старый запрос не должен менять новый экран.
4. Если ссылка по-прежнему не открывается, прислать текст сообщения на экране из этой версии.

Ранее добавленный манифест удаления LogSender должен оставаться в app/src/debug/AndroidManifest.xml. Папка debug находится рядом с main, а не внутри main. Основной манифест не заменять.
