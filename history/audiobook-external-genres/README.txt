AudioBook 4.0 — внешний поиск жанров

Установка: замените MainActivity.kt в существующем проекте и соберите
:app:assembleDebug. PlaybackService.kt и AudioBookWidget.kt менять не нужно.
Этот архив содержит исходники, а не APK.

Поиск → Жанры
- Поиск категорий двух аудиосайтов и внешний поиск запускаются параллельно.
- Google находит страницы аудиокниг и категорий. Если выдачу нельзя прочитать,
  используется Bing. Проверки доступа/CAPTCHA не обходятся.
- Страницы категорий/циклов из выдачи раскрываются в отдельные книги.
- При отсутствии подтверждённых результатов используются публичные главные
  каталоги аудиосайтов как дополнительный список кандидатов.
- Каждая новая страница книги проверяется существующим парсером аудиоглав.
- Для определения жанра учитываются сведения аудиосайта, затем категории
  Google Books и предметы Open Library, затем явные поля «Жанр:» в выдаче.
- Сопоставляются название и известный автор. Разные номера томов сохраняются.
  Неоднозначные названия в библиографических ответах без автора отклоняются.
- Без известного автора для жанра из поисковых фрагментов требуются два
  разных домена. Это снижает риск ошибки, но не устраняет его полностью.
- Выбранный жанр используется для поиска кандидатов. Подтверждение принадлежности
  через библиографию/фрагменты выполняется отдельно: одно слово из запроса,
  названия книги или общий тег Fiction не назначает конкретный жанр.
- Если жанр книги не подтверждён, проверяется известное название её серии.
  Такое определение помечается «по серии»; отдельные книги серии могут отличаться
  по жанру. Перенос жанра серии на книгу является выводом, а не прямым тегом книги.
- Литературные жанры объединяются в шесть существующих категорий интерфейса.
  Неизвестные/неоднозначные метки не назначаются выбранной категории автоматически.

Результаты и управление
- Подтверждённые книги появляются постепенно, с объединением двух аудиоисточников.
- Список показывает, откуда получен жанр.
- Меню книги → «Источники определения жанра» открывает сохранённые ссылки
  на библиографию или страницы, найденные поисковиком, в обычном браузере.
- «Ещё книги этого жанра» загружает следующие категории/пакет внешнего поиска.
- «Повторить поиск жанра» начинает новый поиск; действующий кэш сохраняется.
- За пакет проверяется до 15 страниц, одновременно до трёх кандидатов.
  Время одного пакета ограничено 100 секундами; это не полный каталог жанра.
- Подтверждённые внешние определения кэшируются на семь дней, максимум 160 записей.
  Сведения о жанре/серии также сохраняются в прежних метаданных библиотеки.
- Внешние задачи при выходе из вкладки «Поиск» закрываются. При возврате поиск
  может продолжиться с уже сохранёнными результатами и проверенными адресами.
- «На главную» или новый запрос закрывает задачи предыдущего поиска.
- Прогресс, скачанные главы, очередь, настройки сервиса и виджет сохраняются.

Доступность открытых источников
Для внешнего определения нужны интернет и доступные публичные сервисы.
Передаются название, известный автор и при необходимости название серии;
аудиофайлы не отправляются. Настраивать ключи Google Books/Open Library не требуется.
Публичные сервисы могут ограничивать запросы; Google/Bing могут требовать
проверку доступа или менять разметку. Тогда приложение показывает причину,
использует остальные источники и не подменяет ошибку утверждением, что книг нет.
Ссылки на библиографию не добавляют новые источники воспроизведения аудио:
аудиокниги по-прежнему открываются на Книгоблуде и Bookinfo.

Проверка этого обновления
28 проверок исполнили JavaScript, извлечённый из нового MainActivity.kt,
на подготовленных HTML/JSON-примерах. Проверены прежние категории и серии,
Google Books/Open Library, точное сопоставление названия и автора,
неоднозначные названия, явные жанры в поисковых фрагментах, два домена,
разбор Google/Bing, состояние проверки доступа и получение названия/автора
вместе с аудиоплейлистом. Проверены строки/скобки Kotlin, импорты,
сохранность прежнего opt-in Compose и неизменность PlaybackService.kt.
Это не компиляция Kotlin и не проверка Android-интерфейса.
Запросы к живым сайтам из этой среды не прошли: сетевой прокси недоступен.
assembleDebug не запускался: полного Gradle-проекта и Android SDK здесь нет.
Необходимо проверить сборку и поиск на вашем устройстве.

Далее — инструкция версии 4.0 (обложки, главная, поддержка, версия APK)

AudioBook 4.0 — обновление исходников

Установка
1. Замените MainActivity.kt в app/src/main/java/com/ вашего проекта.
   package в файле: com.audiobookdownloader (как и в предыдущей версии).
2. PlaybackService.kt и AudioBookWidget.kt остаются прежними.
3. Соберите :app:assembleDebug на вашем устройстве.

Обложки скачанных книг
- Обложки читаются из файлов JPG/JPEG/PNG/WebP и URI подключённой папки.
- Добавлено восстановление из встроенной обложки MP3, прежних ссылок,
  метаданных избранного/коллекций и страницы книги.
- При скачивании обложка сохраняется в постоянном хранилище приложения.
  Если папка доступна для записи, туда сохраняются cover.jpg и book_metadata.json.
- Файл book_metadata.json содержит название, адрес страницы и ссылку на обложку;
  аудиофайлы в него не включаются. Он помогает восстановить обложку после переустановки.
- Испорченный cover.jpg заменяется декодируемым изображением, если оно найдено.
- Кэширование, уменьшенные изображения и фоновые загрузки из предыдущего обновления сохранены.
- Для уже скачанных книг: Книги → значок синхронизации → «Восстановить обложки».
  Результат покажет число восстановленных книг.
- Если после переустановки нет доступа к старым изображениям, в этом же окне
  подключите папку AudioBooks через системный выбор папки.
- Если ни файла, ни встроенного изображения, ни адреса книги не сохранилось,
  обложку нужно получить повторным открытием соответствующей книги на сайте.

Главная поиска
- В результатах поиска, категории и на странице книги есть кнопка «На главную».
- Системная кнопка «Назад» с этих страниц тоже возвращает на главную поиска.
- Нажатие на заголовок AudioBook 4.0 возвращает на главную.
- Повторное нажатие нижней вкладки «Поиск» на экране результатов завершает поиск.
- Возврат очищает запрос и результаты и отменяет текущие запросы сайтов.
  Воспроизведение в сервисе продолжается.
- Главная прокручивается к началу; результаты не закрываются автоматически,
  поэтому найденные книги можно сначала просмотреть.

Жанры
- На главной вместо поисковых подсказок используется блок «Жанры».
- Категории обнаруживаются по реальным ссылкам в меню/списке жанров каждого сайта.
- Кнопка жанра не отправляет его название в строку поиска.
- Сначала показываются книги первой страницы категорий двух источников.
- «Ещё книги этого жанра» загружает следующие страницы или использует
  кнопку «Показать ещё» сайта. Дубликаты двух источников объединяются.
- Ссылки на категории запоминаются. Отсутствующая или недоступная категория
  сопровождается сообщением; поиска по словам названия вместо неё нет.

Поддержка разработчика
Настройки (шестерёнка) → «Поддержать разработчика»:
телефон 89128580680, банки Тинькофф, Сбербанк, Ozon.
Кнопка «Скопировать номер» копирует номер в буфер обмена.
Перевод выполняется пользователем в банковском приложении.

Версия APK 4.0
Название интерфейса изменено на AudioBook 4.0.
Версия, показываемая Android в сведениях о приложении, задаётся Gradle.
В app/build.gradle или app/build.gradle.kts внутри android/defaultConfig установите:
    versionName = "4.0"
    versionCode = <текущий versionCode + 1>
Вместо выражения в угловых скобках укажите конкретное число.

Если не хотите менять Gradle-файл, положите прилагаемый audiobook-4.0.init.gradle
в корень существующего проекта и запустите:
    ./gradlew --init-script audiobook-4.0.init.gradle :app:assembleDebug
Он установит versionName 4.0 и увеличит существующий versionCode на 1 для этой сборки.
Файл необязателен, если версия уже изменена в defaultConfig.
Использовать оба способа одновременно не нужно.
