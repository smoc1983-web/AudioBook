Audiobook — четвёртый источник Audiokniga-online.ru
Диагностическая ревизия: 4.0-audiokniga-online-1

ЧТО ДОБАВЛЕНО

1. Общий поиск теперь включает:

   — Азбуку веры;
   — Книгоблуд;
   — Bookinfo;
   — https://audiokniga-online.ru/

Новый источник участвует в той же выдаче, а не в отдельном поисковом
экране. У совпадающих книг сохраняются кнопки доступных источников.
Разные авторы, тома и издания одного сайта не объединяются только
из-за одинакового названия. Из названия удаляется служебная подпись
Audiokniga-online.ru при построении ключа объединения.

2. Поддерживаются прямые ссылки на новый сайт.

Ссылку можно вставить в общее поле поиска. Для распознавания разрешены
точные домены audiokniga-online.ru и www.audiokniga-online.ru.
Адреса страниц поиска, авторов, жанров, правил и других служебных
разделов не выдаются как отдельные аудиокниги.

3. Поиск использует найденную на сайте форму.

Обработчик определяет поле запроса, реальный адрес отправки и метод
GET/POST, сохраняя скрытые поля формы. Если поиск вынесен на отдельную
страницу, используется найденная на сайте ссылка. Учтены формы с q,
story и другими распространёнными именами поля поиска.

Загружаемые на главной книги не считаются готовым ответом поиска.
Ожидаются признаки страницы результатов. Пустая выдача, отсутствие
формы, проверка доступа, HTTP-ошибка и тайм-аут возвращаются как
состояние соответствующего источника. Остальные результаты сохраняются.

Одновременно используется один браузер поиска, чтобы ограничить
потребление памяти. Новому источнику отведено ограниченное время.
Разбор полученных данных и объединение результатов выполняются в фоне.

4. Добавлено чтение карточек и явных данных плеера.

Поддержаны HTML-карточки, в том числе shortstory/short-story,
структурированные данные Book/Audiobook, обложки, авторы и жанры.
Обработчик читает явные данные Playerjs, JWPlayer/setup и setMedia,
списки в контейнерах data-playlist/JSON и обычные элементы audio.
Вложенные папки глав раскрываются с сохранением порядка.

Порядок и названия глав берутся из данных плеера. Подписанные ссылки
с параметрами сохраняются. Строки исполняемого кода из страницы не
вычисляются. Плееры внутри размеченных рекламных блоков и рекомендаций
исключаются. Расширенное распознавание конструкторов плеера включено
только для нового сайта, прежние источники сохраняют свой разбор.

Если плеер явно ссылается на отдельный JSON/TXT/M3U-список того же
сайта, приложение загружает и разбирает его с ограничениями размера,
времени и числа перенаправлений. Относительные ссылки глав разрешаются
относительно адреса списка. Этот запрос получает список глав, а не
полный аудиофайл. Готовые главы затем используют общий плеер и загрузки.

ОГРАНИЧЕНИЯ ПРОВЕРКИ

Получить актуальную страницу audiokniga-online.ru из рабочей среды
не удалось из-за недоступного сетевого прокси. Новая интеграция проверена
на тестовых вариантах разметки; совпадение с текущей версией сайта,
фактическая выдача, воспроизведение и скачивание требуют проверки
на телефоне после сборки.

Зашифрованные данные плеера, сторонние iframe, внешние списки глав
на другом домене и HLS-манифесты эта правка не преобразует в обычные
скачиваемые главы. Если источник передаёт такой формат, приложение
покажет сообщение о недоступном списке глав; можно выбрать другой
источник книги. Куки или заголовки, которые конкретный аудиосервер
может требовать для воспроизведения, отдельно на живом сайте не проверены.

Полный Gradle-проект и Android SDK здесь отсутствуют: APK не собирался,
объединение манифестов и работа Android WebView на устройстве не проверены.
Архив содержит исходники, а не готовый установочный APK.

КАК УСТАНОВИТЬ

1. Сделайте резервную копию файлов проекта.
2. Замените MainActivity.kt по прежнему пути:

   app/src/main/java/com/MainActivity.kt

3. ОБЯЗАТЕЛЬНО замените также помощник объединения книг:

   app/src/main/java/com/SearchBookIndex.java

   В этой правке он изменился. Не вставляйте Java-код внутрь Kotlin-файла.
4. PlaybackService.kt совпадает с предыдущим архивом Audiobook-Source-genres.
   При обновлении с него сервис менять не требуется. При обновлении
   со старых правок перенесите приложенную версию по текущему пути сервиса.
5. Прежние файлы также включены для обновления со старых версий:

   app/src/debug/AndroidManifest.xml
   app/src/main/res/values/audiobook_branding.xml

   Если они уже добавлены, оставьте их. Иначе перенесите по точным путям.
   Папка debug находится рядом с main, а не внутри неё. Объединяйте папки,
   не удаляя остальные файлы проекта.
6. Пересоберите :app:assembleDebug и установите полученный APK.
7. В «Настройки → Диагностика → Диагностика и логи» проверьте ревизию:

   4.0-audiokniga-online-1

Если ревизия другая, установлен прежний APK или заменён другой экземпляр
MainActivity.kt. Очищать данные приложения и скачанные книги не требуется.
