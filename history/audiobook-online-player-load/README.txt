Audiobook — загрузка плеера Audiokniga-online.ru
Ревизия диагностики: 4.0-online-player-load-1

Архив содержит исходники, не установочный APK.
Основано на Audiobook-Source-choice-fix: автоматическая подмена сайта
не возвращается. Выбранный источник сохраняется при ошибках.

ЧТО УСТАНОВЛЕНО ПО ПРИСЛАННЫМ ОТЧЁТАМ

Страница «Моя Космическая Станция. Книга 1» открывается с правильным
названием, но старый обработчик не обнаруживает аудио и список глав.
Оба отчёта 4.0-source-choice-1 заканчивают перечень скриптов после
16 рекламных адресов: реальное объявление плеера туда не попало.

В исходниках обнаружен отдельный воспроизводимый дефект: обработчик
проверял только первые 160 скриптов документа. Он мог пропустить
исправный Playerjs и его данные, если перед ним было много рекламных
вставок. Наличие именно такого количества скриптов на телефоне старый
отчёт не показывает, поэтому назвать этот дефект единственной причиной
ошибки конкретной книги пока нельзя.

Запись о завершении из-за нехватки памяти относится к PID 10333 и времени
12:15:38; свежая проверка страницы выполнялась позднее в PID 26356.
Эта системная запись сама по себе не доказывает, что причиной отсутствия
глав была память, реклама или сбой основного аудиоплеера.

ЧТО ИЗМЕНЕНО

1. Поиск объявления плеера больше не обрывается на первых 160 тегах.
   Сначала выбираются содержательные скрипты из документа, затем
   применяется ограничение разбора. Явные настройки плеера имеют
   приоритет над рекламой и посторонними счётчиками.
   Порядок объявления зависимых переменных сохраняется.

   Число просмотренных тегов ограничено 4000; для подробного разбора
   отбирается до 160 скриптов с суммарным бюджетом текста до 2 МБ.
   Прежние ограничения размера отдельного скрипта и списка глав сохранены.

2. При открытии книги Audiokniga-online.ru фильтруются запросы к конкретным
   рекламным адресам, показанным в ваших отчётах: рекламным путям Яндекса,
   Metrika, TDS, AdRiver, Sape, TerraTraf, Buzzoola, Kimberlite и gtag.
   Это ограничивает запуск соответствующих рекламных загрузчиков.
   Обычные скрипты сайта, файлы плеера и аудио/CDN по общему правилу
   не блокируются. Другие источники не используют этот фильтр.

   Проверка выполняется в обработчике запросов без чтения свойств
   WebView из фонового потока. Число отсечённых запросов выводится
   в ручную диагностику. Фактическое уменьшение памяти на телефоне
   здесь не измерялось.

3. Перед чтением данных выполняется ограниченная подготовка отложенного
   плеера: его контейнер прокручивается в область просмотра, чтобы
   мог сработать штатный обработчик видимости сайта. Для явно указанного
   iframe плеера может быть установлен его собственный data-src.
   Рекламные и рекомендательные контейнеры исключаются.
   Команды play и нажатия на кнопку воспроизведения не отправляются.

4. Диагностика отдаёт приоритет объявлению плеера, а не первым рекламным
   адресам. Дополнительно показываются общее количество тегов scripts,
   число отобранных скриптов, сведения о подготовке контейнера и число
   заблокированных рекламных запросов. Фрагменты ограничены по объёму.
   Отчёт по-прежнему отправляется только вручную из настроек.

Найденные обычные аудиоглавы передаются существующим функциям «Слушать»
и «Скачать». Сам сервис воспроизведения и механизм скачивания не менялись.
Эта правка исправляет обнаружение/инициализацию плеера источника;
отсутствующие аудиоссылки она не подменяет другой книгой.

УСТАНОВКА

1. Сделайте резервную копию MainActivity.kt проекта.
2. Замените его приложенным файлом по пути:
   app/src/main/java/com/MainActivity.kt
3. Соберите :app:assembleDebug и установите полученный APK поверх приложения.
4. В «Настройки → Диагностика → Диагностика и логи» проверьте ревизию:
   4.0-online-player-load-1

При обновлении с 4.0-source-choice-1 остальные файлы менять не нужно.
Очищать данные, библиотеку или скачанные книги не требуется.

ПРОВЕРКА НА ТЕЛЕФОНЕ

Откройте именно этот источник:
https://audiokniga-online.ru/fjentezi/1487-moja-kosmicheskaja-stancija-kniga-1.html

Если список получен, проверьте число и названия глав, запуск звука,
загрузку одной главы и прослушивание этой главы без интернета.
Книгоблуд или Bookinfo не должны открываться автоматически.

Если глав всё ещё нет, нужен только новый раздел «Последняя проверка
источника» из ревизии 4.0-online-player-load-1. Прежние отчёты уже учтены:
повторять весь журнал плеера не требуется. Новый раздел должен показать
объявление плеера или адрес его скрипта, которого не видно в старом отчёте.

ПРОВЕРКИ И ПРАКТИЧЕСКИЕ ОГРАНИЧЕНИЯ

Выполнены 132 сценария JavaScript на синтетической DOM, включая 9 новых:
плеер после 240 рекламных тегов, переменные с главами в конце документа,
ограниченный выбор скриптов, правильный приоритет диагностики, различение
рекламных и обычных URL, отложенная загрузка при прокрутке, data-src iframe
и исключение рекомендаций. Воспроизводимый тест пропуска позднего плеера
отдельно проверен на предыдущей версии: она возвращает null, новая читает главы.

Проверен синтаксис извлечённых JavaScript. Прошли структурные и прежние
регрессионные проверки исходников, включая сохранение выбранного сайта.
Это не компиляция Kotlin и не проверка Android WebView.

Публичный текст страницы доступен через веб-инструмент. Исходный HTML,
внутренние запросы реального плеера и ответы аудиосервера получить в этой
рабочей среде не удалось: сетевой прокси для команд недоступен, запрос
дополнительного сетевого доступа был отменён. Полного Gradle-проекта и
Android SDK здесь нет, поэтому APK не собирался.

Успешное воспроизведение и скачивание именно этой книги не подтверждены.
Если её плеер использует другой формат, требует взаимодействия пользователя
для получения списка, передаёт защищённые данные или нестандартный API,
понадобится уточнение по обновлённой диагностике. Тестовые сценарии не
подтверждают совпадение с фактическим устройством плеера на сайте.

PlaybackService.kt, SearchBookIndex.java, debug-манифест, ресурс названия
и rename_launcher.py совпадают с предыдущим архивом и включены для
обновления с более ранних версий. Сохраняются компактный интерфейс,
жанровая выдача по 20 книг, возврат к поиску, общий поиск четырёх сайтов,
таймер/встряхивание, фоновый сервис, ручная диагностика, удаление книг
и очистка пустых папок. Поддержка: +79128580680; название: Audiobook.
