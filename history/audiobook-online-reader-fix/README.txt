Audiobook — поиск и чтение глав Audiokniga-online.ru
Ревизия диагностики: 4.0-online-reader-2

ЭТО АРХИВ ИСХОДНИКОВ, НЕ ГОТОВЫЙ APK

Обновление основано на Audiobook-Compact-genres. Компактные кнопки жанров,
промежуток между «Другие жанры» и «Все жанры Bookinfo», исправленный вызов
androidx.compose.material3.CircularProgressIndicator и прежние правки сохранены.

УСТАНОВКА

1. Сделайте резервную копию MainActivity.kt своего проекта.
2. Замените его приложенным MainActivity.kt по прежнему пути:
   app/src/main/java/com/MainActivity.kt
3. Если уже установлен Audiobook-Compact-genres или
   Audiobook-Audiokniga-online-compile-fix, остальные файлы менять не нужно.
4. При обновлении с более ранней версии перенесите также:
   app/src/main/java/com/SearchBookIndex.java
   PlaybackService.kt — по текущему пути сервиса в вашем проекте
   app/src/debug/AndroidManifest.xml
   app/src/main/res/values/audiobook_branding.xml
   Не удаляйте остальные файлы проекта. Java не вставляйте внутрь Kotlin.
5. Соберите :app:assembleDebug и установите полученный APK поверх приложения.
6. Настройки → Диагностика → Диагностика и логи:
   проверьте ревизию 4.0-online-reader-2.

Очищать данные приложения и скачанные книги не требуется.

ЧТО ИЗМЕНЕНО

Поиск нового источника:
— Для формы DLE с полями do=search и story используется обычная отправка
  формы браузером. Быстрый AJAX-поиск сайта не должен перехватывать отправку.
— Сохраняются фактические action, method и скрытые поля формы.
— Страница результатов распознаётся также по контейнеру выдачи, когда
  после POST адрес не содержит поисковых параметров.
— Карточки нового сайта разбираются отдельно: ссылки жанра, обложки,
  названия и «Подробнее» на один адрес объединяются в одну книгу.
— Для названия предпочтительны заголовок и блок title; строка жанров
  не должна занимать место названия. Рекламные блоки исключаются.
— Результаты продолжают использовать общий поиск, проверку соответствия
  запросу и прежнее индексированное объединение по всем четырём источникам.

Чтение глав нового источника:
— Поддержаны простые переменные с массивом глав или конфигурацией,
  в том числе объявленные в отдельном inline-скрипте.
— Поддержан JSON-список, помещённый строкой в поле file плеера.
— Данные разбираются как ограниченные литералы: строки страницы
  не исполняются через eval. Вызовы функций и произвольные выражения
  не используются для вычисления конфигурации.
— Добавлено чтение списка из размеченных элементов playlist/player.
— У уже созданного Playerjs запрашиваются данные playlist_folders;
  у JWPlayer используется getPlaylist. Команды запуска звука не отправляются.
— Вложенный iframe того же происхождения может передать главы напрямую.
  Стороннему iframe отправляется запрос данных стандартного API; ответ
  принимается только от соответствующего окна и адреса происхождения.
  Это работает лишь при наличии поддержки такого API у вложенного плеера.
— Явные JSON/TXT/M3U-списки могут загружаться также с отдельного сервера
  источника: сохранены ограничения размера 1 МиБ, времени и перенаправлений.
  Referer передаётся, cookies сайта не отправляются стороннему серверу.
— Порядок, подписи и параметры ссылок глав сохраняются; повторения исключаются.

Карточка и диагностика:
— Обложка открытой книги ищется возле её заголовка, а не среди всех
  изображений страницы. Рекомендации не должны подменять её обложкой
  другой книги. Если подходящей обложки нет, поле остаётся пустым.
— Даже при ошибке чтения глав сохраняются найденные название и обложка.
— В ручной отчёт добавлен раздел «Последняя проверка источника»:
  время проверки, структура формы, адреса скриптов/iframe, сведения
  о найденном плеере и ограниченные фрагменты его объявлений.
  Полные URL медиа из фрагментов и значения скрытых полей не включаются.
  Отчёт сам никуда не отправляется и при запуске не показывается.

ПРОВЕРКА НА ТЕЛЕФОНЕ

1. Найдите «Битва Преемников» общим поиском. Дождитесь ответа четвёртого
   источника; проверьте кнопку Audiokniga-online.ru в карточке книги.
2. Вставьте прямую ссылку:
   https://audiokniga-online.ru/fjentezi/1621-bitva-preemnikov-1.html
3. Проверьте название, обложку, список глав и запуск звука.
4. Проверьте загрузку одной главы и её воспроизведение без интернета.
5. Если ошибка повторяется, откройте ручную диагностику сразу после неё
   и скопируйте раздел «Последняя проверка источника» вместе с ревизией.
   В этом разделе теперь есть сведения о фактическом плеере на телефоне.

ПРОВЕРЕНО И ОГРАНИЧЕНИЯ

Публичные страницы сайта удалось открыть веб-инструментом. Их текст
подтверждает наличие отдельной книги, рекомендаций перед ней и нескольких
ссылок на одну книгу в каталоге. Однако доступное текстовое представление
не раскрывает исходный HTML и код плеера. Нативную поисковую POST-выдачу,
аудиозапросы и работу именно указанной книги здесь проверить не удалось.
Новые способы чтения плеера не подтверждены на этой живой странице.

Выполнены 123 сценария JavaScript на синтетической разметке, в том числе
17 новых сценариев этой правки; проверен синтаксис извлечённых скриптов.
Прошли 12 структурных/регрессионных проверок исходников и прежних функций.
Это не компиляция Kotlin и не запуск Android WebView.

Полный Gradle-проект и Android SDK в рабочей среде отсутствуют.
APK не собирался, воспроизведение и скачивание на устройстве не проверены.
Зашифрованные/защищённые форматы, произвольные выражения JavaScript,
HLS и iframe без доступных данных/поддержки API эта правка не преобразует
в обычный скачиваемый список глав. Если сайт использует один из таких
вариантов, для точной следующей правки потребуется новый раздел диагностики.

PlaybackService.kt, SearchBookIndex.java, debug-манифест, ресурс названия
и rename_launcher.py совпадают с последним компактным обновлением.
