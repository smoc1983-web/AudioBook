AudioBook 4.0 — жанры и серии

Замените только MainActivity.kt в существующем проекте.
PlaybackService.kt и AudioBookWidget.kt менять не требуется.
Архив содержит исходный файл, а не APK.

Что добавлено
- Классификатор данных источников: отдельные словари названий жанров
  Bookinfo и Книгоблуд. Используются реальные ссылки категорий,
  теги карточек и JSON-LD; слова названия книги не определяют жанр.
- На Bookinfo известные маршруты категорий помогают классификации.
  У Книгоблуда UUID не сообщает жанр: проверяются метки сайта.
- Явно указанный жанр карточки/JSON-LD имеет приоритет над маршрутом.
  Если жанров несколько, достаточно совпадения одного с выбранным.
- Карточки без жанров принимаются из действительно открытой категории.
  Посторонние блоки рекомендаций и карточки с другим жанром исключаются.
- Пагинация и «Показать ещё» работают внутри выбранной категории,
  даже если на отдельной странице не оказалось подходящих карточек.
- Ссылки на категории старой версии кэша не используются.

Серии
1. В странице книги — блок «Серия и порядок чтения».
2. В результатах поиска — название серии, номер тома и ссылка на цикл.
3. Книги → «Серии» — группировка вашей библиотеки по данным источника.
   Поиск здесь учитывает название серии, книги и автора.
4. Плеер → «Серия» — сохранённые сведения о текущей книге.
5. Меню карточки → сведения о серии и переход к списку книг.

Порядок извлекается из явных метаданных, позиции книги в списке серии
либо обозначений «Том II», «Книга 3», «Часть 4».
Рейтинг в поиске и обычные числа названия не превращаются в номер тома.
Тома с известными номерами сортируются по номеру. Неизвестные номера
не угадываются: такие книги идут после них, сохраняя порядок источника.
Серия без ссылки отображается, но адрес списка книг не придумывается.
При совпадении названий серий на разных адресах они остаются раздельными;
приложение не может надёжно считать их одним циклом без данных источника.
Список томов в библиотеке формируется лениво, по одной строке на книгу.

Сведения сохраняются в настройках приложения и доступны без интернета.
Для старых скачанных книг откройте источник через меню карточки:
если сайт содержит метаданные серии, они попадут в библиотеку.
После полного удаления приложения эти настройки могут быть утрачены;
из одних MP3 без метаданных нельзя надёжно восстановить принадлежность к циклу.

Проверка обновления
14 проверок на HTML/JSON-LD примерах выполнили JavaScript, извлечённый
из нового MainActivity.kt. Проверены классификация двух источников,
исключение чужих жанров/рекомендаций, приоритет явных тегов, серии без URL,
римские номера, ItemList на странице цикла, пагинация, динамическая
загрузка томов и сохранность извлечения аудиоплейлиста.
Также проверены скобки/строки Kotlin, отсутствие повторных импортов,
сохранность сервиса и прежнего opt-in ExperimentalComposeUiApi.
Это не компиляция Kotlin и не проверка Android-интерфейса.
assembleDebug и APK не проверены: отсутствуют полный Gradle-проект и Android SDK.
Живые сайты в этих проверках не использовались.

Далее — инструкция предыдущего обновления 4.0
------------------------------------------

AudioBook 4.0 — обновление исходников

Установка
1. Замените MainActivity.kt в app/src/main/java/com/ вашего проекта.
   package в файле: com.audiobookdownloader (как и в предыдущей версии).
2. PlaybackService.kt и AudioBookWidget.kt остаются прежними.
3. Соберите :app:assembleDebug на вашем устройстве.

Обложки скачанных книг
- Обложки читаются из файлов JPG/JPEG/PNG/WebP и URI подключённой папки.
- Добавлено восстановление из встроенной обложки MP3, прежних ссылок,
  метаданных избранного/коллекций и страницы книги.
- При скачивании обложка сохраняется в постоянном хранилище приложения.
  Если папка доступна для записи, туда сохраняются cover.jpg и book_metadata.json.
- Файл book_metadata.json содержит название, адрес страницы и ссылку на обложку;
  аудиофайлы в него не включаются. Он помогает восстановить обложку после переустановки.
- Испорченный cover.jpg заменяется декодируемым изображением, если оно найдено.
- Кэширование, уменьшенные изображения и фоновые загрузки из предыдущего обновления сохранены.
- Для уже скачанных книг: Книги → значок синхронизации → «Восстановить обложки».
  Результат покажет число восстановленных книг.
- Если после переустановки нет доступа к старым изображениям, в этом же окне
  подключите папку AudioBooks через системный выбор папки.
- Если ни файла, ни встроенного изображения, ни адреса книги не сохранилось,
  обложку нужно получить повторным открытием соответствующей книги на сайте.

Главная поиска
- В результатах поиска, категории и на странице книги есть кнопка «На главную».
- Системная кнопка «Назад» с этих страниц тоже возвращает на главную поиска.
- Нажатие на заголовок AudioBook 4.0 возвращает на главную.
- Повторное нажатие нижней вкладки «Поиск» на экране результатов завершает поиск.
- Возврат очищает запрос и результаты и отменяет текущие запросы сайтов.
  Воспроизведение в сервисе продолжается.
- Главная прокручивается к началу; результаты не закрываются автоматически,
  поэтому найденные книги можно сначала просмотреть.

Жанры
- На главной вместо поисковых подсказок используется блок «Жанры».
- Категории обнаруживаются по реальным ссылкам в меню/списке жанров каждого сайта.
- Кнопка жанра не отправляет его название в строку поиска.
- Сначала показываются книги первой страницы категорий двух источников.
- «Ещё книги этого жанра» загружает следующие страницы или использует
  кнопку «Показать ещё» сайта. Дубликаты двух источников объединяются.
- Ссылки на категории запоминаются. Отсутствующая или недоступная категория
  сопровождается сообщением; поиска по словам названия вместо неё нет.

Поддержка разработчика
Настройки (шестерёнка) → «Поддержать разработчика»:
телефон 89128580680, банки Тинькофф, Сбербанк, Ozon.
Кнопка «Скопировать номер» копирует номер в буфер обмена.
Перевод выполняется пользователем в банковском приложении.

Версия APK 4.0
Название интерфейса изменено на AudioBook 4.0.
Версия, показываемая Android в сведениях о приложении, задаётся Gradle.
В app/build.gradle или app/build.gradle.kts внутри android/defaultConfig установите:
    versionName = "4.0"
    versionCode = <текущий versionCode + 1>
Вместо выражения в угловых скобках укажите конкретное число.

Если не хотите менять Gradle-файл, положите прилагаемый audiobook-4.0.init.gradle
в корень существующего проекта и запустите:
    ./gradlew --init-script audiobook-4.0.init.gradle :app:assembleDebug
Он установит versionName 4.0 и увеличит существующий versionCode на 1 для этой сборки.
Файл необязателен, если версия уже изменена в defaultConfig.
Использовать оба способа одновременно не нужно.
