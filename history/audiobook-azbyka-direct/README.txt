AudioBook 4.0 — прямой поиск Азбуки веры
Ревизия: 4.0-azbyka-direct-1

Установка
1. Замените MainActivity.kt в app/src/main/java/com/ файлом из архива.
2. Остальные файлы проекта оставьте как в предыдущей версии с исправлением ANR.
3. Запустите :app:assembleDebug и установите обновление поверх приложения.
   Удалять приложение для установки исправления не требуется.

Изменения
- Обычный поиск читает карту каталога Азбуки напрямую, без Google/Bing:
  https://azbyka.ru/audio/karta-sajta
  На сайте проверены переходы к нумерованным страницам, например /karta-sajta/2.
  Приложение следует ссылкам пагинации внутри карты; ограничение — 12 страниц.
- Поиск сопоставляет слова запроса с названием и доступными данными автора.
  Прежнее объединение результатов и источников одной книги сохранено.
- Азбука проверяется первой; Книгоблуд и Bookinfo остаются в едином поиске.
- Под строкой поиска добавлена кнопка «Открыть Азбуку веры →».
- Каталог, страницы книг и «Саморазвитие» загружаются через HTTPS в фоне.
  WebView разбирает HTML без запуска скриптов сайта и загрузки его сторонних
  сетевых ресурсов. WordPress JSON-плейлисты сохраняются для разбора глав.
- Расширен поиск ссылок M3U, если они находятся вне первого блока article.
- Успешные ответы кешируются на 6 часов; размер дискового кеша — до 32 МБ.
  Ошибки источника выводятся в статусе поиска, включая код HTTP или текст ошибки.
- Исправление ANR при проверке скачанных глав сохранено.
  PlaybackService.kt не изменён. Настройки сборки и зависимости менять не нужно.

Проверки
Прошли 50 сценариев разбора HTML/метаданных/M3U на искусственных DOM-примерах,
проверка Kotlin-скобок/строк и структурные проверки предыдущего исправления ANR.
Это не компиляция и не проверка на телефонах. В рабочей среде отсутствуют полный
Gradle-проект и Android SDK, поэтому :app:assembleDebug здесь не запускался.
HTML реального сайта в этих тестах не использовался; публичные страницы и
маршруты каталога исследованы отдельно. Совместимость на Redmi Note 9 Pro
и OnePlus Nord 2T ещё требует проверки установленной версии.

Быстрая проверка после установки
- «Открыть Азбуку веры»: должен появиться её каталог.
- В общей строке поиска: «Лествица» или «Жизнь замечательных детей».
  У результатов Азбуки должен быть указан источник «Азбука веры».
- Жанр «Саморазвитие»: книги из категории «Психология» Азбуки и других источников.
- Откройте книгу Азбуки и проверьте список глав и воспроизведение.
  Если источник недоступен, запишите текст статуса в приложении.
