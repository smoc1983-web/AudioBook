Audiobook — сохранение выбранного источника
Ревизия диагностики: 4.0-source-choice-1

ЭТО ИСХОДНИКИ, НЕ ГОТОВЫЙ APK
Основано на Audiobook-Audiokniga-reader-fix (4.0-online-reader-2).

ПРИЧИНА ОШИБКИ

При выборе Audiokniga-online.ru приложение составляло очередь из трёх
известных источников объединённой карточки. Если выбранный сайт не
передавал главы или возникала ошибка, программа автоматически открывала
следующий источник. Поэтому сначала отображалось «Audiokniga-online.ru,
источник 1/3», а затем появлялась готовая карточка «Книгоблуд».
Это была подмена источника в приложении, а не подтверждённое
перенаправление со стороны Audiokniga-online.ru.

ИСПРАВЛЕНИЕ

— Запрос открытия хранит только одну выбранную ссылку. Автоматической
  очереди переходов между источниками больше нет.
— Ошибка сети, разбора, тайм-аут или закрытие браузера оставляют карточку
  выбранного источника с сообщением об ошибке.
— Другой сайт открывается только после нажатия пользователем
  «Открыть: …» в блоке «Выбрать другой источник» или кнопки в выдаче.
— Повторная попытка использует исходную выбранную ссылку. Она же
  отображается в ошибке, копируется и открывается во внешнем браузере.
— Для выбранного сайта используется его обложка из списка источников,
  если она известна. Ссылка сохраняемых сведений соответствует выбору.
— Нажатие на онлайн-источник больше не открывает скачанную книгу только
  по совпадению названия. Обычное открытие скачанного издания из библиотеки
  или сохранённой полки по-прежнему работает через локальный плеер.
— При загрузке страницы проверяется семейство домена выбранного сайта:
  переход главной страницы браузера на другой источник останавливается.
  Проверка выполняется при запросе перехода, начале загрузки и перед
  приёмом разобранных данных. Встроенные плееры и аудиозапросы на других
  серверах эта проверка не блокирует: она относится к главной странице.
— Счётчик «источник 1/3» удалён: теперь показывается выбранный сайт.

ВАЖНО ДЛЯ ПРОВЕРКИ

Эта правка устраняет подмену выбранного источника. Она не добавляет новых
способов извлечения глав Audiokniga-online.ru: обработчики совпадают с
предыдущим архивом. Если сайт всё ещё не передаёт читаемый список глав,
теперь будет показана его собственная ошибка, а не чужое издание.

УСТАНОВКА

1. Сохраните резервную копию MainActivity.kt своего проекта.
2. Замените его приложенным файлом по прежнему пути:
   app/src/main/java/com/MainActivity.kt
3. Пересоберите :app:assembleDebug и установите APK поверх приложения.
4. Настройки → Диагностика → Диагностика и логи:
   проверьте ревизию 4.0-source-choice-1.

При обновлении с последнего архива менять другие файлы не нужно.
Очищать данные приложения или скачанные книги не требуется.

ПРОВЕРКА НА ТЕЛЕФОНЕ

1. Найдите «моя космическая станция».
2. У первой книги нажмите именно Audiokniga-online.ru.
3. При успешном чтении должна открыться карточка этого сайта.
   Если главы прочитать не удалось, должен остаться Audiokniga-online.ru
   с ошибкой и кнопкой повтора. Книгоблуд не должен открываться сам.
4. Нажмите «Повторить открытие»: проверяется тот же источник.
5. Только после ручного нажатия «Открыть: Книгоблуд» должен открыться
   Книгоблуд. Аналогично проверьте кнопку Bookinfo.
6. Проверьте возврат к результатам поиска и выбранному месту выдачи.
7. При наличии скачанной книги с таким названием проверьте отдельно:
   кнопка сайта открывает его карточку, а книга из библиотеки — локальный
   плеер. Скачанные файлы при этом сохраняются.

Если на Audiokniga-online.ru осталась ошибка глав, сразу после неё
скопируйте из ручной диагностики «Последняя проверка источника».
Раздел сохраняет сведения о фактическом плеере; он не отправляется
автоматически и окно отчёта при запуске не появляется.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ

Прошли структурная проверка Kotlin и прежние регрессионные проверки
исходников. Добавлены проверки сохранения выбранной ссылки, всех ветвей
ошибок, ручного переключения, повтора, локального открытия и защиты
от принятия данных другого сайта.

Извлечённые JavaScript-обработчики побайтно совпадают с предыдущим
проверенным архивом, где выполнялись 123 сценария на синтетической DOM.
Повторный запуск неизменившихся сценариев не проводился.
PlaybackService.kt, SearchBookIndex.java, debug-манифест, ресурс названия
и rename_launcher.py также не менялись.

Полного Gradle-проекта и Android SDK здесь нет. APK не собирался,
Android WebView, перенаправления и воспроизведение на телефоне не проверены.
Эти проверки исходников не заменяют сборку и проверку на устройстве.

ОБНОВЛЕНИЕ СО СТАРЫХ ВЕРСИЙ

Остальные файлы включены для обновления с более ранних архивов:
— app/src/main/java/com/SearchBookIndex.java
— PlaybackService.kt по существующему пути сервиса в вашем проекте
— app/src/debug/AndroidManifest.xml
— app/src/main/res/values/audiobook_branding.xml

Не вставляйте Java внутрь Kotlin. Не удаляйте остальные файлы проекта.
Папка debug находится рядом с main, а не внутри неё.
rename_launcher.py — прежний необязательный помощник подписи приложения.
