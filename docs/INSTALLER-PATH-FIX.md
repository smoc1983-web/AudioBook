# Исправление запуска установки из Audiobook

На телефоне владелец разрешил установку из Audiobook Preview 4.2-preview.48, но после нажатия кнопки обновления оставался экран «APK проверен. Подтвердите установку в Android».

Причина подтверждена по оригинальному APK 48: загрузчик сохраняет файл в cache/app-updates/, а preview_update_paths.xml разрешал FileProvider только cache/preview-updates/. Поэтому getUriForFile отклонял реальный путь ещё до запуска системного установщика. Затем общий обработчик завершения проверки заменял сообщение об ошибке стандартным текстом об успешной проверке. Разрешение Android не исправляет этот дефект.

Исправление:

- FileProvider открывает только нужную подпапку cache/app-updates/. Остальной кеш и закрытые настройки не становятся доступны.
- Проверка APK и запуск Android выполняются последовательно; ошибка запуска больше не заменяется текстом «APK проверен».
- Сохраняется ожидание разрешения при пересоздании экрана. Результат/отмена системного установщика показываются отдельно.
- В инструментальные тесты добавлены чтение реального APK через provider, запрет доступа к постороннему приватному файлу, открытие настоящего установщика Android с доступной кнопкой Install/Update и сохранение ошибки некорректного APK.

Первое обновление со сломанной версии 48–53 необходимо открыть как файл. Код уже установленного обновлятора нельзя исправить изменением файла на сервере.

1. Откройте https://audiobook-smoc1983-updates.amplecoot2048.chatgpt.site в Chrome.
2. Нажмите «Подготовить скачивание», затем «Сохранить APK».
3. В «Мои файлы → Загрузки» откройте полученный APK и выберите «Обновить». Если Android попросит разрешение, оно относится к «Моим файлам», поскольку именно они открывают APK.
4. Не удаляйте Preview/Audiobook и не очищайте её данные. Тот же пакет и подпись позволяют обновить установленную новую Audiobook с сохранением её библиотеки и настроек. Отдельная прежняя стабильная Audiobook не заменяется.

Если скачивание APK зависает, сохраните ZIP с той же страницы, распакуйте его в «Моих файлах» и откройте APK внутри. Подтверждение установки остаётся системным действием пользователя. Сообщение Samsung о собственном блокировщике требует отдельной диагностики; по присланному экрану неизвестных источников оно не установлено как причина ошибки.
