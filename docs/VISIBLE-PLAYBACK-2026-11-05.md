# Производительность: этап 8

Из общего счётчика изменений метаданных исключены book_progress_* и
book_duration_*. Они сохраняются прежним способом; исключение относится только
к пересозданию UI-кэшей. Завершение книги, описание, обложка, серия, коллекции,
закладки и явная очистка настроек по-прежнему обновляют интерфейс.

Экран получает StateFlow плеера только пока Activity видима. При возврате
сразу получает последнее состояние; сервис, сохранение позиции, гарнитура и
виджеты работают отдельно. Загрузка обложек из скрытой Activity отменяется
на границе coroutine; уже начатый блокирующий запрос может завершиться в пределах
своего таймаута. Новые запросы скрытым экраном не запускаются. Lazy-списки и
отложенная загрузка во время прокрутки сохранены.

Граница checkpoint сначала дала ожидаемый падающий тест, затем оба теста прошли.
Локально полный unit, AndroidTest Kotlin/Java compile и lint успешны. Native
проверяет число подписчиков: 1 → 0 в фоне → актуальная позиция при возврате.
Существующий тест 600 карточек проверяет возврат/догрузку/края списка и пик
одновременно созданных карточек <40. Его время подготовки и пик сохраняются
в search-scroll-metrics.json среди отчётов CI. Это замер эмулятора, не FPS
физического телефона; сравнения скорости с прежним выпуском пока нет.
