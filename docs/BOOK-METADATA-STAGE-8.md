## Пользовательский результат

В меню скачанной книги — «Изменить сведения». Можно задать отображаемые
название, автора, чтеца, личную подпись серии и номер тома. Сохранение явное;
«Отмена» не пишет данные. Сброс требует подтверждения и возвращает данные
источника. Номер тома — положительный десятичный, до 9999.99, разделитель точка;
текстовые поля — до 512 символов, название обязательно.

Название в файловой системе и исходные сведения сохраняются. Личная серия —
подпись, а не автоматическая перегруппировка книг или доказательство связи
продолжений. Запросы к источникам по-прежнему используют исходные сведения.

Правки применяются к библиотеке (строки/плитки, фильтр и сортировка), заголовку
описания, плееру и мини-плееру, MediaSession/уведомлению и заголовку виджета.
В библиотеке можно искать по исходному и новому названию, автору, чтецу и личной
серии. Действия, файлы, обложки и расчёт времени используют прежние ключи.

## Хранение и совместимость

- Отдельная schema1 JSON-запись `book_metadata_override_v1_<bookId>`; bookId,
  editionId и chapterId не меняются. Повторное получение каталога не стирает правки.
- Известные издания используют существующий b3-ID; неизвестные локальные книги —
  существующий l3-ID. У неоднозначной локальной записи редактор не предлагается.
  Прежние ограничения title-only BookRef/коллекций не объявляются устранёнными.
- ServiceTrack получил необязательный presentation metadataId (`m` в JSON).
  Java-конструктор с четырьмя аргументами сохранён через @JvmOverloads.
  Старые плейлисты читаются без него. Для известного издания допустим b3 fallback;
  неизвестной старой записи нужен повторный запуск той же локальной книги,
  чтобы получить l3-привязку. Угадывания только по названию нет.
- Сохранение проверяет снимок открытого редактора; устаревшая правка отклоняется.
  Исходный снимок и черновик сохраняются при пересоздании окна.
  Запись идёт на IO с отдельным writer lock. Чтение во время записи показывает
  последнее подтверждённое значение. Неудачный commit не выдаётся за сохранение;
  завершение обновляет StateFlow для интерфейса и службы без перезапуска аудио.
- Повреждённый JSON/неверный тип не затираются. Явный сброс сначала сохраняет
  raw/type в private `book_metadata_damaged_v1_<bookId>`; первый снимок не заменяется.
- В backup allowlist добавлены только валидируемые overrides, не grants/секреты
  и не аварийные снимки. Нестабильная локальная привязка l3 не переносится угадыванием
  на другую папку/устройство. SAF/Яндекс progress-only обмен остаётся progress-only.
- Кэш декодированных overrides ограничен 64 записями по 8К символов; source cache
  — 64 записи, не кэширует fingerprints свыше 64К. Это лимиты, не измерение RAM.

## Ограничения

Физический телефон, OEM-прошивки, реальная установка APK, power loss/process kill,
диск без свободного места и межустройственный перенос неизвестного l3-издания не
проверены. Failed/blocked commits проверяются моделированием. Полный исторический
native suite не обещается: выбранные классы перечислены в native-tests.sh.
Изменение SeriesAuthorityCache без обновления сохранённого каталога может оставить
исходную подпись серии в presentation cache до следующего изменения каталога или
перезапуска; личная подпись серии от этого не зависит.

Этап 8 целиком не завершён. Далее — отдельный пакет автоматической загрузки
следующего тома по Wi-Fi с явным согласием пользователя, затем фильтры поиска.
