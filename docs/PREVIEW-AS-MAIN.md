# AudioBook: основной пакет, который раньше назывался Preview

Актуально на 23 ноября 2026 года. С 25 октября основная разработка уже велась в Preview-пакете после утраты ключа прежней Stable. 23 ноября владелец **успешно получил и установил обновление 4.2.100 → 4.2.101 прямо из приложения на Samsung**.

## Основная AudioBook

- Код: ветка **`main`**.
- Установленный Android-пакет: **`com.audiobookdownloader.preview`**.
- Рабочая версия: **4.2.101 / versionCode 100101**.
- Сертификат: SHA-256 `3a4cecd14bb3e983843871766909c3f07b3dc64379800f3e270e4a27d39affb7`.
- Каталог: `AudioBooks-Preview`.
- Встроенный обновлятор: теги `preview-v<versionCode>`, APK `Audiobook-Preview.apk`, файл `preview-update.json`.
- Отображаемое имя — **Audiobook**; изменение технических package/tag/file разрушит обновления существующих установок, поэтому историческое слово Preview остаётся только в технических идентификаторах.
- Текущий релиз: https://github.com/smoc1983-web/AudioBook/releases/tag/preview-v100101 .

Новые обычные коммиты в `main` только собираются и проверяются. Публикация подписанного основного APK выполняется отдельно после проверки изменений и разрешения владельца через `.github/workflows/release-main.yml`.

## AudioBook Test — отдельное приложение

- Код: ветка **`test`**, изменения и эксперименты вносить сначала сюда.
- Android-пакет: **`com.audiobookdownloader.test`**.
- Видимое имя **Audiobook Test**; каталог **`AudioBooks-Test`**.
- Собственный встроенный канал обновления: `test-v<versionCode>`, APK `Audiobook-Test.apk`, JSON `test-update.json`.
- Стабильный сертификат тестового APK обязателен для установки следующей версии поверх предыдущей; стартовое хранилище подписи — исходный Preview-keystore, но package и данные полностью раздельные.
- Каждый push в `test` по пути app/current/scripts с релизной сборкой проходит CI и публикует тестовый выпуск после проверки. Следующий тестовый выпуск доступен из меню обновления тестового приложения.
- После ручных проверок переносить исправления в `main` отдельным pull request.

## Прежняя Stable 1.0

`com.audiobookdownloader` — историческая установка с утраченным приватным ключом, несовместима с работающим пакетом `com.audiobookdownloader.preview`. Её сборка и скрипты ручной подписи **удалены из активной структуры**. Исторические коммиты и прежние релизы оставлены как архив; не используйте их для новой разработки.

**Не удаляйте пользовательскую установку, пока не убедитесь, что в старой Stable не осталось нужных книг, настроек или коллекций.** Основная и тестовая приложения не используют её закрытые данные автоматически.
