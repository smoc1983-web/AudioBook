# Preview как основное приложение

25 октября 2026 владелец выбрал дальнейшее использование и обновление Preview рядом с прежней стабильной Audiobook. Исходный ключ стабильной версии не требуется. Готовая подписанная сборка 4.2-preview.48 уже поддерживает этот режим; код и APK для инструкции не менялись.

## Установка на телефон

1. Если GitHub зависает на завершении загрузки, используйте [загрузку без GitHub](https://audiobook-smoc1983-updates.amplecoot2048.chatgpt.site): «Подготовить скачивание» → «Сохранить ZIP с APK». Откройте ZIP в «Моих файлах», распакуйте и запустите APK. Открывайте страницу в полном Chrome через меню ⋮, если встроенный браузер не сохраняет файл. Альтернативно: [скачать подписанный APK Preview 48](https://github.com/smoc1983-web/AudioBook/releases/download/preview-v100048/Audiobook-Preview.apk). Открыть скачанный файл и подтвердить установку Android. Если Preview уже установлена с той же подписью и меньшей версией, выбрать «Обновить». Старую Audiobook оставить установленной.
2. Открыть **Audiobook Preview → Книги → Синхронизация библиотеки** (значок круговой стрелки). В пустой библиотеке также есть «Подключить папку».
3. Нажать **«Выбрать папку библиотеки»**, найти **Внутренняя память → Download → AudioBooks**, открыть её и подтвердить **«Использовать эту папку» / «Разрешить»**. Выбирать подпапку AudioBooks, а не корень Download. Подключается общая папка скачанных аудиофайлов, не закрытая папка данных старого приложения.
4. Дождаться синхронизации. Если нужно, нажать «Синхронизировать» повторно. Выбор папки сохраняется через системное разрешение Android. Повторно скачивать доступные завершённые аудиофайлы не требуется.

Папка старых книг не переносится и не очищается при подключении. Новые загрузки Preview сохраняет в **Download/AudioBooks-Preview**; сканер объединяет их со явно выбранной старой папкой. Не используйте команды удаления книг, если хотите сохранить общие файлы для обоих приложений. Старые настройки, коллекции и позиции находятся в прежнем приложении и автоматически в Preview не переносятся. Скопировать их закрытые данные одним разрешением на аудиопапку Android не позволяет. Старую Audiobook и её данные не удалять.

Установку APK и доступ к папке подтверждает сам владелец на телефоне. Удалённая установка на физический телефон здесь не выполнялась.

## Последующие обновления

**Настройки Preview → Обновления → Проверить обновления → Загрузить обновление → Установить загруженное обновление.** Android подтверждает обновление. Приложение между выпусками не удалять; библиотека, разрешение папки и настройки самой Preview остаются в её установке. GitHub-подключение в приложении не требуется. Текущий опубликованный feed соответствует версии 48; при установленной 48 он сообщает, что версия последняя.

Для следующих выпусков сохранять пакет **com.audiobookdownloader.preview**, исходный сертификат Preview **3a4cecd14bb3e983843871766909c3f07b3dc64379800f3e270e4a27d39affb7**, default-каталог **AudioBooks-Preview**, текущий origin HTTPS-канала и путь **updates/preview-update.json**. Назначение Preview основным приложением не означает замену package на com.audiobookdownloader или смену ключа. versionCode должен расти. Все новые функции поставлять в подписанном APK Preview.

CI сохраняет свой ключ в закрытых cache/recovery artifacts и не должен генерировать новый при наличии опубликованного канала. После успешных проверок подписанный Preview APK публикуется в GitHub release и отдельный публичный канал через tools/package-public-update.py и существующий Sites project. Публичный канал содержит только файлы выпуска и описание версии; никакие signing keys туда не входят. Неподписанные stable-кандидаты пользователю для этого режима не нужны, stable-feed остаётся неактивным. Подробности — PREVIEW-UPDATES.md и PREDANIE-AND-DIRECT-UPDATES.md.

## Проверка готового APK

Повторно проверены apksigner, applicationId, versionCode, сохранённая подпись Preview и совпадение публичного описания версии с полным SHA-256 локального подписанного APK. Ранее выполненные проверки выпуска: 170 JS, по 69 JVM и 8 Android 36. Выбор папки на физическом Samsung S24 ещё должен подтвердить владелец. Результат проверки APK/канала — verification/preview-as-main-2026-10-25.json.
