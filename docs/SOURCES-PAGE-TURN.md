# Четыре источника и перелистывание

По запросу пользователя восстановлены Азбука веры, Книгоблуд, Bookinfo и Audiokniga-online.ru. LibriVox и Internet Archive исключены из активных каталогов. Кнопка «Источники · 4» позволяет выбрать один сайт или «Все четыре источника». С непустым запросом выбор сразу запускает поиск; без запроса сохраняется режим для следующего поиска. «Общий поиск» возвращает все четыре сайта. Восстановлены прежние обработчики открытия книг, каталога и жанров.

Загрузки, история и сервис воспроизведения не изменяются. Совместимость открытия ранее сохранённых Archive-изданий оставлена отдельно; в поиске этот источник не предлагается. Preview устанавливается поверх предыдущей Preview с сохранением данных, стабильное приложение остаётся отдельным.

Свайпы влево/вправо переключают соседние разделы «Поиск → Книги → Плеер → Коллекции». Переход показывает сдвиг страницы, лёгкий 3D-поворот и тень края; занимает 380 мс. На крайних разделах переход за границы отсутствует. Обычная вертикальная прокрутка и собственные горизонтальные обработчики элементов работают по правилам Compose. Переход не запускает и не останавливает звук. Состояния страниц сохраняет существующий SaveableStateHolder.

## Проверки

- 120 сценариев настоящих извлечённых JS-обработчиков: поиск по авторам, каталоги/жанры, формы и ответы Audiokniga-online, Playerjs/PHP/M3U, исключение рекламы и посторонних адресов. Все прошли локально; это DOM-фикстуры, не доказательство доступности сайтов.
- CI собирает APK и выполняет JVM-тесты, затем Android 36 инструментальный тест с включёнными анимациями. Проверяются запуск, четыре источника и исключение прежних двух, выбор Bookinfo/общего поиска, пересоздание Activity, свайпы в обе стороны, аварийный TXT-отчёт и экран обновлений.
- Аудит HTTP главных страниц сохраняется в source-evidence/availability.json отдельно от функциональных проверок. Доступная главная не доказывает получение глав или скачивание произвольной книги; внешние ограничения описываются в отчёте.

Аудит с GitHub от 21 октября 2026: все четыре главные страницы вернули HTTP 200 без проверки доступа в заголовке; исходный JSON сохранён в verification/preview-four-source-http-2026-10-21.json. Это не подтверждает полный цикл скачивания каждой книги.

Первая сборка #14 скомпилирована и открыла главный экран, но тест был закрыт системным окном «Process system isn't responding». Это подтверждено сохранёнными иерархией и скриншотом артефакта android-startup-test-reports, run 39559840421. Тестовый обработчик уже ожидал System UI/Google Play services/Phone; добавлен только известный системный Process system. Ошибки Audiobook и неизвестных приложений обработчик не закрывает. Публикация #14 была заблокирована проверкой Android.

Сборка #15 подтвердила выбор четырёх сайтов, режим Bookinfo, сохранение выбора и первый свайп в библиотеку. Тестовый второй свайп попал в горизонтальный ряд сортировки (координата y=400 при 540×1200), и ряд обработал жест, сохранив страницу — ожидаемое поведение вложенного горизонтального элемента. В тесте дальнейшие свайпы перенесены на свободную область y=3/4 высоты, после завершения перехода. Приложение из-за этого не изменялось. Публикация #15 также была заблокирована.

Сборка #16 снова показала работающий главный экран, но его перекрыло окно «Pixel Launcher isn't responding»; ошибки приложения и сохранённого стека нет. Отчёт: run 39567443754. В тестовую разрешённую группу добавлен только Pixel Launcher. Чтобы снизить нагрузку на программный GPU CI, разрешение эмулятора уменьшено до 360×800 при density=140: логический размер экрана остался прежним (411×914 dp). В одноразовом эмуляторе отключена фоновая первоначальная настройка Play Services; у приложения нет зависимости от GMS. Эти изменения относятся только к окружению проверки; APK не менялся.
