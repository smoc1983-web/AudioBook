# Audiobook Test — журнал приёмочных проверок модернизации Nova

Статус: ожидается тестирование на телефоне. Ни один пользовательский результат ещё не внесён.

Записывать каждую проверку с версией APK, датой, устройством/Android, режимом VPN, идентификатором, статусом PASS / IMPROVE / FAIL / NOT_TESTED, сценарием и наблюдением. Не заменять прежние результаты новыми: хранить историю повторных проверок.

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| N01 | Общий поиск | Ошибка одного сайта не отменяет остальные | NOT_TESTED |
| N02 | Локальная база | После сетевого поиска и перезапуска доступны ранее найденные метаданные | NOT_TESTED |
| N03 | Навигация | Возврат к открытой книге и восстановление последнего поиска | NOT_TESTED |
| N04 | Цикл | Книги раскрывают озвучки, порядок томов сохраняется | NOT_TESTED |
| N05 | Точное название | Фильтр исключает соседние тома с похожими названиями | NOT_TESTED |
| N06 | Полнота аудио | Демо и несоответствие названия обозначаются; неизвестное не считается проверенным | NOT_TESTED |
| N07 | Резервный источник | Нет бесконечного повторения адресов | NOT_TESTED |
| N08 | Счётчики | Ответы, ошибки, кэш и ожидание различаются | NOT_TESTED |
| N09 | Кэш | Повторный поиск использует кэш, обновление повторяет сетевой запрос | NOT_TESTED |

| N11 | Подсказки | История и локальные названия | NOT_TESTED |

| N17 | Эквалайзер | Ручные диапазоны и сохранение профиля | NOT_TESTED |
| N18 | Регрессия | Обновление поверх предыдущей версии, библиотека и прогресс не потеряны | NOT_TESTED |

Не завершено: единое автоматическое объединение локальной и сетевой выдачи; рейтинг по сопоставимым подтверждённым оценкам; подтверждение реального воспроизведения каждого источника; поиск новых резервов за пределами уже известных изданий; проверка разрешений новых источников; полноценная дедупликация подписок по идентичности серии. Ручная проверка на Android обязательна.
