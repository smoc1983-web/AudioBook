# Тест обновления 4.2.55 → 4.2.57 из приложения

Этот выпуск подготовлен для проверки перехода с исправленной Audiobook 4.2.55 через три кнопки встроенного обновлятора. Функциональное изменение — подсказка, что после установки новый номер появится вверху окна обновлений. Пакет, ключ подписи, каталог библиотеки, формат коллекций и плеер сохраняются.

## На телефоне

1. В установленной Audiobook 4.2.55 откройте «Настройки → Обновления».
2. Нажмите «Проверить обновления», затем «Загрузить обновление».
3. После проверки APK нажмите «Установить загруженное обновление» и подтвердите обновление в Android.
4. Откройте приложение и проверьте номер 4.2.57 вверху окна обновлений. Убедитесь, что коллекции, доступ к библиотеке и сохранённое место прослушивания остались на месте.

Удаление приложения и очистка данных для этого теста не нужны. Если всё ещё установлена версия 48–53 с ошибкой запуска установщика, сначала нужен переход через APK из «Моих файлов» по инструкции INSTALLER-PATH-FIX.md. Тест внутриприложенческой установки начинается с исправленной 55.

## Автоматическая проверка

В одноразовом Android 36 эмуляторе устанавливается опубликованная 55 и сохраняются контрольные настройки, коллекция, путь папки и приватный файл. Тест выполняет проверку нового APK кодом установленной старой версии, копирует его в её настоящий кеш загрузчика и вызывает её установщик. Проверяются системное окно Android и доступная кнопка Update/Install. Через instrumentation status передаётся отдельное подтверждение этого этапа; System.out не используется как доказательство в выводе am instrument.

Подтверждение установки в этом UI-тесте не нажимается: после проверки окна выполняется Back. Далее CI-хост заменяет установленный пакет через adb install -r и отдельным тестом проверяет сохранение контрольных данных и разрешений. Полная загрузка через сеть и нажатие подтверждения на физическом Samsung проверяются владельцем.
