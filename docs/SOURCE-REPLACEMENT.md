# Проверка и замена источников — 21 октября 2026

> Исторический отчёт по версии 4.1. По последующему запросу пользователя в Audiobook восстановлены четыре прежних сайта; актуальное состояние — [SOURCES-PAGE-TURN.md](SOURCES-PAGE-TURN.md). Сведения о ForTanya ниже остаются отдельной историей музыкального проекта.

В активные каталоги включены только адаптеры, подтвердившие поиск, получение URL, загрузку 400 000 байт аудио и декодирование двух секунд из локального файла. Это проверка реальных источников, а не HTML-страницы с кодом 200. Полное скачивание произвольного большого файла и установка на конкретный телефон этим тестом не подтверждаются.

## ForTanya 0.4

- Internet Archive: музыка и концерты; из общего пользовательского аудио берутся записи с музыкальными тегами. Поддержаны поиск, альбомы, очередь и скачивание отдельных треков.
- Audius: поиск и прослушивание. Скачивание доступно, только когда API предоставляет разрешённую автором ссылку; платные/закрытые потоки исключаются.
- Radio Browser: проверенные HTTPS-потоки, только онлайн.
- Hitmo и Zaycev.net удалены из активных каталогов. Выполнение скриптов сайтов и зависимость публичного воспроизведения от CookieManager/WebView удалены.
- Пользовательская онлайн-коллекция, файлы телефона, избранное, плейлисты, темы и фон сохранены.

## AudioBook 4.1

- LibriVox через фактическую коллекцию librivoxaudio Internet Archive.
- Другие аудиокниги Internet Archive, коллекция audio_bookspoetry без дублей LibriVox.
- Русский язык выбран по умолчанию; есть переключение на все языки.
- Предыдущие четыре сайта убраны из активного поиска. Старые скачанные файлы и сохранённые данные не удаляются.
- Главы упорядочены по номеру; дубли MP3 разного битрейта объединяются. Названия получают порядковый номер для предотвращения коллизий файлов.
- Добавлен полный Gradle-проект, рабочая совместимость компонента AudioBookWidget и независимая APK-сборка.

Каталоги отличаются от прежних сайтов: наличие конкретной современной песни или книги, включая ранее скачанных авторов, не гарантируется. Текстовый поиск использует метаданные источника; написание имени/названия в них может отличаться.

## Что не включено после проверки

- z3.fm: главная доступна, но проверка поиска получила HTTP 502; воспроизведение не подтверждено.
- Musify: поиск отдаёт карточки, однако проверенная ссылка скачивания открыла авторизацию вместо аудио. Встраивание неподтверждённого MP3 не выполнено.
- Tancpol: найдены методы собственного плеера, но полный цикл получения аудио не подтверждён.
- Аkniga: проверенные запросы поиска не дали читаемых карточек; рабочий полный цикл не подтверждён.
- Baza Knig: доступная главная сама по себе не подтверждает извлечение глав; источник не включён.
- Прямые запросы API LibriVox в пробном прогоне вернули 404. Записи LibriVox подключены через прошедший проверку Internet Archive.

## Установка

APK находятся в ZIP-артефактах GitHub; скачивать через браузер с авторизацией владельца репозитория. Распаковать app-debug.apk. Для установки поверх существующей версии нужны тот же пакет и исходный ключ подписи. Пользовательский ключ не предоставлялся: GitHub debug-подпись может отличаться. Удалять приложение или очищать данные для проверки не предлагается.
