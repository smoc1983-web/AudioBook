## Что реализовано

### Проверка сохранённой книги

В существующем управлении хранилищем появилась кнопка проверки файлов книги.
Проверяются локальный доступ, фактическая аудиоструктура существующим валидатором,
достоверный размер завершённого задания своего издания и полный SHA-256.
Сохраняется отдельный локальный отпечаток; изменение требует явного принятия новой базы.
Проверка не скачивает, не удаляет и не исправляет файлы, не меняет очередь и прогресс.
Её можно отменить; незавершённый проход не записывает частичную базу отпечатков.

Глава в активной очереди откладывается. Повреждённая/недоступная очередь не считается
пустой. Отсутствующие главы определяются только по известному оглавлению; неполное,
повреждённое и неоднозначное оглавление явно помечается, совпадение названий не угадывается.
Первый локальный хеш не подтверждает подлинность с сервера. Проверка структуры не является
полным декодированием записи. Автоматический ремонт и новая очередь повторной загрузки
в этот пакет не входят; прежнее скачивание сохранено.

На Android 6 системному MediaExtractor передаётся явный размер дескриптора: без него
валидный ADTS AAC мог не давать аудиодорожку. Расширение файла критерием отказа не стало.

### Автоматические локальные копии

В существующем разделе резервных копий — переключатель «Выключено / Раз в сутки»,
немедленное создание, выбор для существующего восстановления и экспорт через Android.
По умолчанию выключено. WorkManager: уникальная периодическая задача, 24 часа,
ограничения низкого заряда/места, без требования сети. Android может отложить запуск.

Копируются разрешённые существующим LibraryBackup позиции, закладки, коллекции,
метаданные и настройки; без аудио и секретов. Внутреннее отдельное хранилище сохраняет
семь проверенных архивов. Сначала запись во временный файл, fsync, валидация и уникальное
переименование; только затем удаляются старые исправные архивы этого хранилища.
Повреждённые прежние архивы сохраняются. Чужие файлы/симлинки не чистятся. Сбой или
отмена не заменяет исправную прежнюю копию. При откате часов новые копии сортируются
логически после предыдущих. Ошибки записи и очистки видны пользователю.

Перед восстановлением нужно поставить плеер на паузу; выбранная книга закрывается,
чтобы её кэш не перезаписал восстановленную позицию. Самостоятельного запуска звука нет.
Выбранный для экспорта архив и ожидающий результат системного окна переживают
пересоздание интерфейса. Отсутствующий системный выбор файлов обрабатывается сообщением.

Внутренние копии **не переживают удаление приложения или потерю телефона**.
Для этого нужен отдельный экспорт. Настройки подключения к провайдерам в архивы не входят.

### Обмен прогрессом: общая папка и Яндекс Диск

Выбор владельца сохранён: **Android Storage Access Framework**, в том числе Яндекс Диск
через системный выбор папки. Встроенного OAuth, client_id, пароля или токена не требуется.
Два независимых подключения находятся в разделе резервных копий. Передача только вручную:
выбрать папку → отправить позиции либо показать файлы → предпросмотр → подтвердить замену.
Автоматической синхронизации/фонового опроса облака в этом пакете нет.

Яндекс доступен этим способом **только если установленный провайдер предоставляет
дерево папок с постоянными правами чтения/записи и созданием документов**.
Наличие кнопки не означает, что аккаунт подключён. Если Диск не предлагает такую папку,
данный способ на этом устройстве недоступен. Запись с последующим чтением подтверждает
сохранение у провайдера, но не доставку на сервер Яндекса.

Файл обмена содержит только стабильные editionId/chapterId, позицию внутри главы,
необязательное название для предпросмотра, случайный ID устройства и время отправителя.
Ссылки, аудио, аккаунты, коллекции и закладки не передаются. Package текущего канала,
схема, ID, целые позиции, отсутствие повторных изданий и лимит 4 МиБ проверяются.
Чужой пакет/канал, изменившийся файл и несовместимое локальное оглавление отклоняются.
Список ограничен 500 копиями/5000 документами; большие списки требуют отдельной папки.

Новый файл создаётся с уникальным именем, затем перечитывается. Внешние копии автоматически
не удаляются. При сбое новая неполная копия может остаться у провайдера; получение её
отклонит. Отключение убирает только настройку, без удаления файлов и отзыва общего
разрешения, которое может использовать библиотека.

Свежая локальная позиция после предпросмотра отменяет применение. Сопоставление идёт по
устойчивым ID, а не по заголовку. Нулевую/более раннюю позицию можно явно получить;
сравнение часов устройств или автоматический выбор максимального прогресса не используется.
Перед применением закрывается текущая приостановленная книга, выполняется повторная
проверка локальных значений. Это не распределённое слияние одновременного прослушивания.

выбора с выдачей постоянного разрешения, 24 часа ожидания и перезагрузка устройства

регрессия/Android Installer не измерялись и не проверялись. Список локальных копий показывает 12 последних архивов; остальные оригиналы сохраняются.
