# Прокрутка больших результатов поиска

Обнаружено по коду: экран поиска синхронно пересчитывал циклы всех (до 600) книг при каждой рекомпозиции, включая обновления состояния плеера. Ключ справочника для каждой записи повторно вычислял SHA-256 с форматированием каждого байта. Поиск скачанной версии перебирал библиотеку внутри карточки. AbPageTurn при каждом обычном кадре записывал весь экран в дополнительный GraphicsLayer. Карты блокировок обложек росли без ограничения при посещении новых адресов.

Изменения:

- AbSearchRows подготавливает снимок карточек в Dispatchers.Default, один раз при изменении результатов, библиотеки или ревизии справочника серий. На старую задачу распространяется отмена корутин.
- Индекс локальных книг сохраняет прежнее правило: точное название имеет приоритет, нормализованное совпадение допустимо только при единственном варианте. Подтверждённый прямой цикл и прежний порядок томов сохранены.
- Ключи справочника сохраняются в ограниченном LRU (1024), сериализованный ключ и сохранённые сведения совместимы с прежними версиями. Проверка справочников остаётся фоновой, 2 запроса одновременно.
- LazyColumn использует стабильный URL и общий contentType для переиспользования полных карточек. Первый список не измеряется пустым до подготовки снимка, чтобы не сбить восстанавливаемую позицию.
- Промах обложки ждёт остановки прокрутки. Фоновые загрузки ограничены прежними 3 слотами, отмена проверяется при чтении потока. Ошибка временно запоминается на 30 секунд (до 256 записей), ручное восстановление очищает её. Пул блокировок фиксирован (32+32), вместо постоянно растущей карты. Размер LRU изображений прежний: 16 МиБ.
- GraphicsLayer записывается только для действительного загиба страницы, с ожиданием записанного кадра перед чтением текстуры. Обычная вертикальная прокрутка рисуется напрямую.

Проверки включают настоящие карточки с жанрами, серией и кнопками источников, 600 результатов, вертикальный свайп, перемещение до последней книги и назад, открытие/возврат и добавление результатов с сохранением позиции. Обложки в этом тесте без сетевых адресов; время HTTP и полный поток онлайн-аудио им не измеряются. Отдельный нативный тест проверяет прямой цикл «Хранитель кладов», исключение из «Отдел 15-К» и неоднозначные локальные названия. Существующие проверки текстурного перелистывания и реального обновления с сохранением данных остаются обязательными.

Статус на момент изменения исходников: Android-сборка и нативные проверки ещё не запускались. Числовое улучшение FPS на Samsung S24 не заявлено: для него требуется замер на физическом устройстве с библиотекой владельца.
