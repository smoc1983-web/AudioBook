# Audiobook Preview 4.2.96 для проверки на телефоне

Архив доступен владельцу репозитория после входа в GitHub. GitHub Actions хранит его 14 дней. [Скачать архив](https://github.com/smoc1983-web/AudioBook/actions/runs/44287342156/artifacts/14420780320).

Внутри находится `dist/Audiobook-Preview-4.2.96.apk`. Размер 33,432,404 байт. SHA-256 `d790f671cb8c3333e257a6abcafdb07ff8abd5635eb3d04c90d745e4b4cf8f6a`.

Подписанный релиз APK принят Android 16 поверх опубликованной Preview 4.2.95. Совпала подпись, приложение запустилось, тестовые настройки, коллекция, запись позиции, закладка с заметкой и аудиофайл сохранились. Установщик открывался из старого приложения после проверки APK, а замену пакета выполнил ADB. Проверка сборки не охватывала сетевую загрузку кандидата из меню. Модульные тесты Release прошли, 423 успешно и 1 прежний пропуск. Lint прошёл без ошибок. [CI](https://github.com/smoc1983-web/AudioBook/actions/runs/44287342156).

1. Откройте текущее приложение, отметьте книгу, главу и время. По возможности сделайте резервную копию настроек и прогресса.
2. Войдите на GitHub, скачайте архив Audiobook-Preview-4.2.96-phone-test, извлеките dist/Audiobook-Preview-4.2.96.apk и откройте его через «Мои файлы». В окне Android выберите «Обновить». Если Android сообщает о несовместимости, сохраните текст ошибки. Прежнее приложение удалять не нужно.
3. Откройте Audiobook. Убедитесь, что на месте книги, коллекции и закладки и что прослушивание продолжается с прежней главы и позиции.
4. Выполните знакомый поисковый запрос. Откройте «Фильтры поиска», введите имя чтеца, пролистайте результаты, затем сбросьте фильтры. Проверьте порядок томов и плавность прокрутки.
5. Если для серии уже найден следующий том, временно выключите Wi-Fi. В плеере откройте «Серия → Следующий том по Wi-Fi» и подтвердите один том. Проверьте, что загрузка аудио ждёт подключения к обычной сети Wi-Fi. Включите Wi-Fi и проверьте, началась ли загрузка.
6. Сделайте перемотку назад и вперёд. Закройте приложение обычным способом, снова откройте его и проверьте главу и позицию.

Если что-то пошло не так, запишите номер пункта, версию Android и точный текст ошибки. Для проблем с воспроизведением запишите название источника и номер главы.
