Нативные Java-адаптеры вернули по 20 результатов русскоязычных записей из LibriVox и другого каталога Internet Archive. В проверенных записях получены соответственно 28 и 1130 MP3-файлов. По каждому каталогу загружено 400 000 байт (HTTP 206), затем ffmpeg декодировал две секунды из локального файла. Дополнительно прошли семь JVM-тестов каталога, 40 000 проверок книжного индекса и 22 проверки восстановления библиотеки.

Gradle выполнил Kotlin/Java-компиляцию, тесты, сборку ресурсов и assembleDebug. Полный Gradle-проект восстановлен из сохранённых прикладных исходников и ресурсов; исходные неизвестные Gradle-файлы и ключ подписи пользователя не выдаются за восстановленные оригиналы.

Для дальнейшей проверки на телефоне: искать название/автора, переключать источник и язык, открыть книгу и главы, послушать, скачать главу, воспроизвести без сети, проверить старые книги в библиотеке, виджеты и настройки.

Скачивание ZIP не требует его предпросмотра в чате. Нужен вход в GitHub владельца приватного репозитория. Обновление поверх установленной версии требует исходного ключа подписи; GitHub debug-ключ может отличаться. Удаление приложения и очистка пользовательских данных не требуются для переноса исходников и не предлагались.
