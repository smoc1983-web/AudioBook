Доступ к release/файлам требует входа владельца закрытого репозитория GitHub.
Первую Preview установите отдельно, не удаляя стабильную Audiobook. Книги стабильной
версии остаются в ней. У Preview собственная папка `Download/AudioBooks-Preview`.
Дальнейшие обновления доступны через «Настройки → Обновления Preview». Однократно
подключите доступ GitHub непосредственно в приложении: fine-grained token только
для AudioBook с Contents: Read-only. Подтверждение установки выполняет Android.

## Подтверждённые проверки

Gradle выполнил Kotlin/Java-компиляцию, сборку ресурсов, 14 JVM-тестов и assembleDebug.
Это семь тестов каталогов, шесть тестов правил обновления и один live-тест источников:
настоящий поиск, список глав, получение MP3 и декодирование аудио ffmpeg.
Тесты обновлений проверяют отдельный пакет/каталог, отказ для старой версии и
другого пакета, корректность hash/размера, выбор самой новой версии и отсутствие
передачи ключа GitHub при перенаправлении на CDN.

CI проверил фактический APK через aapt/apksigner, затем успешно опубликовал APK и
preview-update.json. После скачивания ZIP выполнена независимая проверка размера,
SHA-256, двоичного AndroidManifest.xml, названия, отключённого backup, отдельных
provider authorities и SHA-256 публичного сертификата из META-INF.

Сопоставлены готовые APK 100009 и 100010: одинаковый отдельный пакет, одинаковая
подпись, возрастающий versionCode. Результаты находятся в verification/preview-100009.json
и verification/preview-100010.json. Инструмент: tools/inspect_preview_apk.py
(проверка v1-сертификата не заменяет выполненный в CI apksigner verify).

## Проверка на телефоне

В этой среде нет Android-устройства. Не подтверждены реальной установкой:
параллельный запуск двух приложений, системный запрос разрешения на установку APK,
возврат в Preview после выдачи разрешения и сохранение её прогресса после обновления.
Не требуется удалять стабильное приложение, очищать его данные или перемещать книги.

## Подпись и история

Автопубликация работает из main; ручные сборки рабочих веток выпускают artifact без
публикации обновления. Весь исходный код и история книг остаются в AudioBook;
музыкальный ForTanya не изменялся. Для долгосрочного хранения ключа подписи владелец
должен сохранить закрытый recovery artifact и настроить repository secret по
PREVIEW-UPDATES.md. Сейчас ключ восстановлен и проверен между последовательными сборками.
