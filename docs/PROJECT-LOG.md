## Хронология решений и обсуждений

### 2026-11-25 — единый контекст между чатами

**Требование владельца.** Сохранить договорённости и работу над AudioBook между чатами внутри проекта ChatGPT «Книга», а также при переходе от `test` к `main`, чтобы не повторять всю историю и не начинать работу заново. Изначальный запрос включал весь разговор как лог-файл.

**Согласованное решение.** Поскольку репозиторий публичный, вести в нём общую **техническую** хронику задач, решений, ошибок, проверок и релизов; не переносить приватную переписку дословно. Хранить **единственную каноническую копию на `main`**, а из `test` и QA давать ссылки на неё. Любой новый агент сначала читает [регламент](AI-WORKFLOW.md) и этот журнал, а потом проверяет фактическое состояние GitHub. Автоматическая синхронизация всех реплик ChatGPT в GitHub **не настроена и не заявлена**.

**Область разрешённых изменений.** Только документы/инструкции GitHub на `main`, `test`, QA; код, подпись APK, выпуск, версия приложения и пользовательские данные не менять. Публичные GitHub-документы не должны раскрывать секреты.

### 2026-11-25 — активный QA: подписки на серии

**Требование.** В «Коллекции» отдельно управлять ручными подписками на серии: подписка из серии в плеере, список циклов, ручная проверка, отписка, правильная очередность томов, объединение источников, честные статусы наличия аудио/только текста/анонса. При этом автоотслеживание коллекций должно быть независимо от ручных подписок. Кнопку «Настройки» перенести в нижнюю навигацию.

**Подтверждённые изменения в QA-ветке.** Модель и сохранение подписок, список и действие отписки, выборочная проверка цикла, правила группировки томов, JVM-тесты, Compose UI; подробности и коммиты — [ACTIVE-QA.md](https://github.com/smoc1983-web/AudioBook/blob/qa/series-subscriptions-navigation-20261125/docs/ACTIVE-QA.md). Это фиксация записанного кода, **не доказательство успешного APK**.

**Дальнейшие действия.** Сверить HEAD PR и GitHub Actions, устранить любые ошибки, пройти регрессию и проверку подписи/обновления; после готовности объединить **только в `test`**. Прежде чем переходить в `main`, отдельно запросить команду владельца.
