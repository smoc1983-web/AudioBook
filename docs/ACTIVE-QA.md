## Текущая задача

Полноценное управление ручными подписками на циклы в «Коллекции», отделённое
от слежения за книгами в коллекциях; список томов по правильному порядку,
раздельные статусы аудио / только текст / ожидается, проверка цикла и всех
подписок, отписка, сохранение данных; перенос кнопки «Настройки» вниз.
Только `test`, `main` нельзя менять без нового прямого разрешения.

## Что проверить и закончить

1. Проверить актуальный HEAD PR и запущенные Actions по нему.
2. Проверить компиляцию Compose/Kotlin и корректность полей `BookRef`/
   `BookLink`, компонентов экранов и обработчиков.
3. Проверить ручную подписку → закрытие/перезапуск → список подписок,
   открытие цикла, правильный порядок, объединение издательских источников,
   разграничение подтверждённого аудио и текстовой версии, отписку.
4. Проверить независимость автоматического слежения за коллекциями,
   отсутствие повторных оповещений, работу ручного и периодического запуска,
   сохранение данных и обновление поверх установленного тестового APK.
5. При красном CI открыть конкретные логи, исправить ошибку, снова запустить QA.
6. Лишь после успешных проверок объединить PR в `test` и дождаться
   `build-test.yml`; зафиксировать конкретную ссылку на run, SHA, тег релиза,
   статус подписи, загрузку APK и появление обновления внутри Test.
7. Основную ветку не менять без разрешения пользователя.
