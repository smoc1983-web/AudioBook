# Постоянные правила разработки AudioBook

## Работа и выпуск
- Пользователь преимущественно тестирует с телефона Android, Samsung S24. Нужны готовые решения, а не фрагменты и длинные объяснения. Не спрашивать повторно разрешение на уже порученную работу.
- Основное приложение и Test независимы. main/preview не менять без отдельного явного поручения. Test package com.audiobookdownloader.test, main package com.audiobookdownloader.preview.
- Если пользователь просит пока не собирать, копить изменения в отдельной pending-ветке. При выпуске проверить фактический head, CI, итоговый релиз и его assets.
- Сохранить исходную подпись и совместимость обновления поверх установленного APK. Не генерировать другой ключ. Секреты только в защищённой конфигурации CI, не в Git.
- Не удалять коллекции, скачанные главы, настройки, историю, прогресс, данные библиотеки при обновлении.
- Автотесты JVM Debug/Release, парсеры, lint, проверка подписи, функциональный Android-эмулятор и установка подписанного APK поверх предыдущего. Не отключать тест ради публикации.
- Честно различать: внесено в код, прошло JVM, прошло эмулятор, проверено на телефоне, опубликовано. Отдельно отмечать ограничения живых сайтов.

## Поиск — обязательный контракт
- Сначала предварительная библиографическая сверка с Author.Today и Литрес, затем поиск аудио. Свежий кэш справочников допустим, при недоступности не заявлять успешную сверку.
- Проверять название, автора, номер тома, подтверждённый состав цикла. Нельзя подставлять другой том, одно совпавшее число, произвольные рекомендации сайта. Нативный searchQuery — происхождение результата, не доказательство совпадения.
- Цикл сохраняет порядок и число подтверждённых книг даже при отсутствии аудио. Текстовые/неподтверждённые тома отмечать отдельно. Не выдавать справочник за рабочую аудиоверсию.
- Общая и локальная выдача должны быть согласованы; офлайн база использует сохранённую библиографию без обязательной сети.
- История, подсказки, кэш, отмена старых задач, возврат к выбранной книге с подсветкой и сохранением прокрутки/озвучки/источника.
- Приоритет найденных глав и проверенных изданий. Пустой плейлист временно исключать, повторная проверка через 15 минут. Не исключать навсегда из-за временной недоступности.
- Суммарный подтверждённый размер <20 000 000 байт — демо по объёму, скрыть; 20–<30 млн — «ДЕМО?» на обложке, возможный фрагмент; >=30 млн — обычные проверки. Размер не гарантирует полноту, неизвестный/частичный объём не считать демо. Старый неполный size-cache не использовать для отбраковки. Сохранять проверки названий глав, длительности и признаков демо.
- При ошибке открытия попробовать другое уже известное подходящее издание; дать кнопку «Найти в других источниках». Не повторять бесконечно один адрес.
- Сайты использовать в пределах разрешённого доступа. Не обходить блокировку правообладателя, авторизацию, DRM или защиту. Не подтверждать наличие полной легальной аудиокниги только по каталогу.
- VPN не принуждать: пользователь подтвердил, что без VPN выдача обычно шире, отдельные сайты выигрывают от VPN.

## Интерфейс
- Вкладки Поиск, Книги, Плеер, Коллекции. Разделять MainActivity постепенно; не переписывать всё.
- Плеер: время до конца главы и книги, независимое скрытие этих показателей. Кнопка общих настроек на плеере; собственное меню: эквалайзер, скорость, таймер сна (внутри ночное расписание), после паузы, встряхивание, панель плеера.
- Удалить дубли этих пунктов из общих настроек. Продолжения оставлять в меню книг. Каталог и тумблер скрытия прослушанных из общих настроек удалены; старый тумблер не должен скрывать книги.
- Мини-плеер поиска скрывается горизонтальным свайпом без остановки воспроизведения; возвращается при посещении плеера или выборе другой книги. Другие вкладки без изменения.
- Экран обновлений: установленная версия, список изменений последнего выпуска сразу даже офлайн, кнопка «Проверить обновления», при новой версии — скачивание/установка. Нет лишних пояснений, окна после обновления и отдельной вкладки «Что нового». Не удалять системные разрешения и защиту подписи.
- Сохранять размер APK около 16 МБ, не жертвовать надёжностью ради уменьшения.
