# Закладки: названия, заметки, список библиотеки

Пользователь одобрил ub-mode на всю последовательность. Новый релиз не публикуется.

Данные закладок вынесены из MainActivity в BookmarkStore. Дополнительные поля
читаются с пустыми значениями, старые JSON сохраняются. Новый ключ содержит SHA256
полного названия книги. При первом изменении старый список читается, затем копия
с изменением пишется под новым ключом; старый ключ не удаляется. Сохранённый пустой
список не позволяет удалённым закладкам вернуться из старого ключа. Старые коллизии
без исходного названия нельзя восстановить однозначно; не заявляем их исправление.

Стабильный id сохраняется при редактировании. Старая запись получает детерминированный
id, новая — UUID. Запись хранит исходную главу, точное время, создание, название,
заметку и, когда известны, editionId/chapterId. Новая закладка не переходит в другую
озвучку. Изменённый порядок глав разрешается по идентификатору, старые записи —
по единственному точному названию. Недостающая или повторяющаяся глава даёт сообщение.

Редактор доступен в плеере и библиотеке; заметка многострочная. Общее представление
на вкладке «Закладки» ищет по книге, названию, заметке и главе. Построение списка
выполняется на IO. Для текущей книги можно перейти к моменту; другая открывается
в карточке, затем её закладки доступны из плеера. Автоматической загрузки другой
книги по закладке в этой реализации нет. Старые записи показываются для известных
библиотеке книг, новые содержат исходное название и видны даже вне текущего списка.

названия/заметки без изменения времени/id. Локальный JS syntax-check выполняется.
