# Ветки и релизы AudioBook

**Единственные рабочие ветки после реорганизации 23.11.2026:**

| Ветка | Роль | Пакет | Релизный канал |
|---|---|---|---|
| `main` | Основная установленная AudioBook | `com.audiobookdownloader.preview` | `preview-v...` (ручной проверенный выпуск) |
| `test` | Проверка всех новых функций | `com.audiobookdownloader.test` | `test-v...` (отдельный CI) |

## Правила

1. Для поиска/озвучек/скачивания сначала создавать ветку от `test`, проверять и объединять только в `test`.
2. Убедиться, что test APK имеет прежний пакет `com.audiobookdownloader.test`, неизменный сертификат, новый versionCode и успешно устанавливается поверх предыдущего test APK.
3. После проверки на устройстве открывать PR `test` → `main`; не менять Android-пакет production и не переносить test-метаданные релизов.
4. Новую основную версию выпускать только через ручной workflow `release-main.yml`. Не публиковать при обычном push в main.
5. Не перезаписывать старые APK/JSON в GitHub Releases: каждый номер имеет собственный новый tag.

## Исторические ветки

Ветки `audit/*`, `build/*`, `feature/*`, `cloud/*`, `fix/*`, `integration/*` (кроме активного короткого review-процесса) — архив предыдущих задач. Не выбирать их для очередной сборки приложения. Они **не удалены из GitHub**: в их истории остаётся много диагностических и контрольных данных. Дальнейшее удаление старых refs можно выполнять отдельной очисткой после анализа незавершённых задач; не удалять старые коммиты и релизы без нужды.

Историческая Stable `com.audiobookdownloader` версии 1.0 — архив. Её исходного ключа подписи нет; не использовать старую схему `Audiobook-stable-UNSIGNED.apk`. Исходная версия с рабочими обновлениями 4.2.101 — это Android-пакет, технически заканчивающийся на `.preview`.
