# Ошибка доступа к обновлению на установленной 4.2.62

27 октября 2026 владелец прислал два экрана: сначала «Канал обновлений пока закрыт для загрузки», затем `Unable to resolve host … No address associated with hostname`. Первое сообщение в старом PreviewUpdater означает HTTP 401/403. Второе — отказ DNS-разрешения на устройстве; его нельзя трактовать как отсутствие опубликованной версии, несовпадение подписи или ошибку установщика.

Проверено без изменения приложения и хостинга: Site активен, аудитория public, feed содержит 4.2.66. Запросы с точными заголовками установленного 62 (`User-Agent: Audiobook-Updater/4.2.62`, `Accept: application/json`, `Accept-Encoding: identity`) из текущего исполнителя получили HTTP 200. Публичные Google DNS и Cloudflare возвращают A-записи сервера. Фактический APK 62 использует этот же origin. У APK 62 и готового 66 совпадают package и сертификат, versionCode возрастает 100062 → 100066. Это подтверждает совместимость файлов, но не исправление сети телефона.

На телефоне: переключить Wi-Fi/мобильную сеть, при наличии VPN переподключить его и проверить исключения Audiobook, затем полностью перезапустить приложение и повторить проверку. Если вручную задан персональный DNS, проверить режим «Автоматически» в настройках Android. Не отключать Play Protect, не удалять приложение и не очищать его данные. При доступной странице скачивания можно открыть готовый 66 APK через «Мои файлы» и выбрать «Обновить»; повторная сборка ради той же подписи не требуется.

Сеть телефона, причина первого HTTP 401/403 и фактическое получение обновления устройством пока не подтверждены. Не заявлять, что DNS на телефоне уже восстановлен. Origin, аудитория, APK, подпись, источники и поиск серий не менялись. [Сводка проверок](verification/update-access-2026-10-27.json).
