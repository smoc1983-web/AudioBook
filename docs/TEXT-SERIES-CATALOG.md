# Текстовые и аудиопродолжения

В плеере → «Серия» и в настройках продолжений добавлен каталог официальных изданий Литрес и Author.Today. Проверка каждого справочника независима: точные название/автор → собственная страница произведения → прямая серия → явно перечисленные книги этого автора. Миры и рекомендации не подменяют прямой цикл. Дубликаты форматов и площадок объединяются по автору, прямой серии и названию, не только по номеру тома.

Карточка показывает формат (текст/аудио/не указан), номер при наличии, статус (опубликовано, пишется, анонс/предзаказ, только запись в каталоге), источник и дату последней успешной сверки. Поддержаны мобильная и настольная разметка Author.Today, включая карточки поиска со ссылкой на внешнем контейнере, и счётчик номера Литрес. При повторной сверке сначала проверяется ранее подтверждённая страница произведения: её серия и автор читаются заново, чтобы не зависеть от ранжирования широкого поиска. Кнопки ведут на официальные страницы: каталог не даёт прав на платный текст или аудио и не загружает их через аудиопарсеры приложения. «Доступно» означает опубликованное издание у указанной платформы; условия доступа определяет она.

Фильтры: все форматы / текст / аудио; продолжения / вся серия. Если порядок не подтверждён, это указано явно. Различия прямых серий и нумерации показываются пользователю и блокируют текстовые уведомления. Загружаются до 6 страниц и 500 изданий на справочник, только страницы той же серии. Нераскрытый список «ещё» помечается неполным; он не продвигает состояние уведомлений.

Хранилище `files/official-series-v1` содержит только метаданные, атомарные JSON до 1 МиБ, не более 80 файлов. `official_series_v1` хранит ревизию для UI. Снимки читаются и обновляются вне потока интерфейса. При ошибке остаются прошлый список, дата его успешной проверки и причина неудачи. Кэш автоматически обновляется через 12 часов, ручная кнопка принудительная. Общая фоновая проверка сверяет до 2 коллекционных книг за проход с сохранением курсора; остальные можно сверить сразу из карточки серии. Отдельный клиент ограничивает запросы и объём, не расходуя бюджет аудиоисточников.

`continuations_v1.text_enabled` по умолчанию false. Первая полная проверка после включения создаёт тихую базу, включая случай отсутствия продолжений. Затем новые опубликованные/пишущиеся текстовые тома с явным большим номером создают одно уведомление независимо от числа площадок. Предзаказы, неполные списки, конфликтующие серии/номера, отключённые и удалённые подписки уведомлений не создают. Старые уведомления без поля формата остаются аудио, отмеченные/прочитанные записи сохраняются.

Проверки: восемь JVM-тестов парсера (включая сокращённую действительную мобильную разметку 27.10.2026) и нативные тесты двух справочников, первого пустого состояния, нового тома, повтора, офлайна, неполного списка, отключения подписки, конфликтов и фильтров UI. Исходные сетевые страницы сохранены только во временном каталоге; в репозитории — библиографические метаданные без глав. Android-компиляция и CI на момент изменения исходников ещё не выполнены.
