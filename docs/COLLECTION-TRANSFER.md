# Перенос коллекций из прежней Audiobook

Новая Audiobook (пакет `com.audiobookdownloader.preview`) и прежняя стабильная (`com.audiobookdownloader`) имеют отдельные настройки. APK не содержит пользовательские коллекции. Доступ к папке AudioBooks переносит аудио, но не закрытый список полок.

В новой версии: **Коллекции → Перенести коллекции** либо **Настройки → Перенос и копия коллекций**.

## Если есть JSON/XML копия

Выберите «Импортировать JSON/XML», проверьте число коллекций и нажмите «Добавить найденные коллекции». Поддерживаются отдельный экспорт AudiobookCollections v1, массив shelves_v1 и файл SharedPreferences XML. Экспорт новой версии сохраняет только коллекции, без других настроек или ключей.

## Прямое чтение через Shizuku

Доступно только для прежнего APK с разрешённой отладкой (`FLAG_DEBUGGABLE`) в основном профиле Android. Debug-сертификат сам по себе не означает, что APK отладочный. Экран проверяет совместимость заранее. По инструкции официального Shizuku владелец запускает его через беспроводную отладку и разрешает Audiobook выполнить перенос. Служба читает только фиксированный файл прежнего пакета командой системного run-as, извлекает только shelves_v1 и завершается. Root не требуется. Платёжные данные, ключи подписи и остальные настройки не копируются. Закрытый релизный APK этим способом не читается.

## Если прямое чтение запрещено и копии нет

1. Нажмите «Начать перенос с экранов». В специальных возможностях Android включите **Перенос коллекций Audiobook**. При блокировке Android разрешите ограниченные настройки именно новой Audiobook в сведениях о приложении.
2. Откройте старую Audiobook. Перейдите в «Коллекции» и прокрутите общий список полок.
3. Откройте каждую полку и прокрутите все книги до конца. Вернитесь к общему списку перед следующей полкой.
4. Вернитесь в новую Audiobook, нажмите «Завершить чтение экранов и проверить», затем подтвердите добавление.

Это ручной перенос названий и принадлежности к коллекциям, а не постоянная фоновая синхронизация. Переносятся только полки, число прочитанных книг которых совпало со счётчиком старого приложения; неполные пропускаются. Скрытые адреса и обложки этим способом недоступны. Скачанные книги открываются по совпадению названия после подключения прежней папки AudioBooks; для остальных открывается поиск по названию. Новые ссылки можно добавить после нахождения книги.

Служба читает только видимые элементы старого пакета, игнорирует поля ввода/пароли, не выполняет жесты/нажатия и не отправляет данные в сеть. Чтение активно лишь в запущенном пользователем сеансе, ограниченном десятью минутами. После завершения служба отключает себя. После закрытия процесса незавершённый сеанс нужно начать заново.

## Сохранность

Импорт объединяет полки по названию и добавляет отсутствующие книги; повторный импорт не создаёт дубликатов. Существующие непустые адреса/обложки имеют приоритет. Удаления из старой версии не удаляют ничего из новой. Перед изменением сохраняется внутренняя копия. «Отменить последний импорт» доступна, пока коллекции после импорта не менялись.

Старая Audiobook, её данные, аудиофайлы и ключи не изменяются. Не удаляйте прежнее приложение до проверки переноса. Автоматический доступ к закрытым данным Android без разрешения владельца не заявляется.
