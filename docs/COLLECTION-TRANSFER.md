# Перенос и резервное копирование коллекций

С версии 4.2.63 устанавливаемый APK не содержит службы чтения экранов, Shizuku, AIDL-моста или доступа к закрытым данным старой Audiobook. Исторические реализации сохранены вне исходников приложения в history/privileged-collection-transfer-4.2.62. См. [разбор предупреждения Play Protect](PLAY-PROTECT.md).

1. Откройте «Коллекции» → «Перенести коллекции».
2. «Сохранить копию коллекций» создаёт JSON-файл в выбранном через Android месте.
3. «Импортировать JSON/XML» открывает системный выбор файла. Поддерживаются копии Audiobook и XML с сохранённым shelves_v1; прочие настройки из XML не копируются.
4. После проверки показано число новых полок и книг. До нажатия «Добавить найденные коллекции» изменения не вносятся.
5. Импорт дополняет текущие полки без дубликатов. Перед изменением сохраняется внутренняя копия.
6. «Отменить последний импорт» восстанавливает копию, если полки после переноса не менялись. Поздние изменения не перезаписываются.

Импорт коллекций не перемещает и не удаляет аудио. Скачанные книги подключаются отдельно: «Книги» → синхронизация → выбор папки библиотеки. Уже перенесённые в новую Audiobook полки сохраняются при обновлении.

Если старая версия не умеет экспортировать коллекции и сохранённой копии нет, её закрытые настройки недоступны новому приложению. Добавляйте скачанные книги в новые полки вручную. Старую Audiobook для этого удалять не требуется.
