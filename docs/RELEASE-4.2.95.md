# Audiobook 4.2.95 / 100095

Опубликована с разрешения владельца в Preview с прежними пакетом и сертификатом.

- [Скачать APK](https://github.com/smoc1983-web/AudioBook/releases/download/preview-v100095/Audiobook-Preview.apk)
- [Релиз](https://github.com/smoc1983-web/AudioBook/releases/tag/preview-v100095)
- [Успешная сборка и публикация](https://github.com/smoc1983-web/AudioBook/actions/runs/42860160270)

Добавлены встроенный поиск/скачивание Audioknigi.top и встроенное окно для шести
ранее внешних сайтов: открыть книгу, проверить явный список глав, выбрать скачивание.
Число глав, доступный размер и выбор отдельных глав используют существующий загрузчик.
Ссылки подключённых источников заменены действием «Найти и скачать».

Это не гарантия доступности всех книг: ошибки сайтов, проверки соединения,
закрытое аудио и неподдержанные плееры могут мешать скачиванию. Подробности:
[SOURCE-DOWNLOADS-2026-11-10.md](SOURCE-DOWNLOADS-2026-11-10.md).

CI успешно выполнил Release unit/build/lint, проверку исходного сертификата,
размера и SHA-256; APK и metadata принадлежат одному релизу. После публикации
production Java updater без авторизации выбрал95, полностью скачал APK,
сверил его с собранным APK и независимым digest GitHub. Метаданные повторно
прочитаны анонимно 2026-11-11. Доказательство: [publication.json](release-4.2.95/publication.json).

Физическая установка и полный цикл скачивания книг на телефоне не проверялись.
GitHub updater обнаруживает95 через меню обновления. У старых клиентов, которые
ещё обращаются только к прежнему сайту, переход не гарантируется: при недоступном
старом адресе нужен разовый APK поверх установленной Preview, без удаления данных.
Stable — другой пакет; этот APK не является обновлением Stable.
