Доступность главной страницы, чтение сохранённого HTML и наличие URL не доказывают успешное воспроизведение либо скачивание всей книги на телефоне. Полные аудиофайлы в ходе проверки не скачивались. Доступ может зависеть от сети, региона, сессии и ограничений правообладателя. Ограничения сайтов, CAPTCHA и закрытые издания не обходятся.

Канонический реестр и JS-обработчик: `app/src/main/java/com/audiobookdownloader/AdditionalBookSources.kt`. Kotlin и JavaScript используют один JSON-реестр с точными именами хостов, проверкой схемы, отсутствия userinfo и посторонних портов. Формы берутся с фактической страницы; скрытые поля и метод сохраняются. При разборе данных плеера не вызывается eval. Новый обработчик подключается только на дополнительных хостах, прежние четыре продолжают идти по прежним веткам.

В `current/tests/fixtures/screenshot-sources` сохранены небольшие фрагменты публичной разметки и данных. Рекламные исполняемые библиотеки, поля сессии и CSRF исключены, подписи тестовых URL заменены фикстурами. `current/check.py` извлекает действующий JS из Kotlin перед проверками. Добавлены 43 сценария JS и четыре JVM-проверки реестра; Android smoke test проверяет новый список, сохранение выключенного источника, прежние источники и сохранение отдельного режима после recreate.

Исследование публичных страниц сохранено отдельно в ветке `integration/screenshot-source-audit`: сборки 39638152985, 39638944180 и 39640234099. Это исследовательские workflows, без APK, подписи и публикации. Их workflow нельзя переносить поверх основного build-apk.yml.

Preview по-прежнему использует пакет `com.audiobookdownloader.preview`, прежнюю подпись и отдельную папку AudioBooks-Preview. Стабильная версия и скачанные книги не мигрируют и не удаляются.

## Сетевой плеер и повторная проверка

Нативный MediaPlayer и DownloadManager теперь используют общую функцию заголовков: фактический User-Agent скрытого WebView, Referer сохранённой страницы и CookieManager.getCookie **для адреса самого аудио**. Cookie страницы не копируется на чужой CDN, значения не включаются в отчёт. Четыре JVM-теста проверяют сетевую сессию, отсутствие заголовков у локальных файлов, недопустимые Referer и переводы строк в заголовках.

Первый прогон 39642736163: JS, JVM, запуск, новый список и сохранение выбора прошли; Android проверка аварийного отчёта обнаружила обрезанную кнопку закрытия в узком диалоге. APK этого прогона не опубликован. Высота текста в нативном отчёте ограничена 55% экрана; кнопки остаются полностью видимыми. Повторный прогон проверяет закрытие по системному id кнопки и исчезновение диалога. Перелистывание, коллекция и виртуальный акселерометр в первом прогоне прошли.

Дополнительно проверено размещение Playerjs вне блока .book-details у Uknig: метка ознакомительного фрагмента определяется и в таком случае.
