# Дополнительные фильтры поиска

Откройте «Фильтры поиска» в результатах. Можно ввести имя или фамилию чтеца, оставить книги из серий или издания, главы которых есть на устройстве. Фильтры можно сочетать со скрытием подтверждённых демо. «Применить» обновляет результаты. «Сбросить фильтры» возвращает исходную выборку, если ничего не найдено.

Фильтры работают с загруженными результатами. Они действуют и на следующие порции по мере подгрузки. Выбор чтеца ищет совпадение без учёта регистра и различий «е/ё» в имени, указанном источником. Для серии нужны сведения каталога или справочника. Для локального совпадения нужны доступные главы и однозначный идентификатор издания. Достаточно одной главы. Книги без связи с конкретным изданием доступны через библиотеку.

Фильтрация выполняется в фоне до объединения озвучек и разбивки на страницы. Порядок томов определяет прежний алгоритм. Выбор фильтров хранится в состоянии экрана, а настройка скрытия демо сохраняется между запусками.

Код прошёл проверку в [CI](https://github.com/smoc1983-web/AudioBook/actions/runs/44279866534). Локально прошли два теста правила чтеца, проверки исходников и фикстур парсеров. CRAP для правила чтеца равен 2, Dryer не нашёл дублирования на проверенном участке, тесты обнаружили единственную мутацию Mutator. Android SDK локально отсутствует.

Сборки Stable Debug и Release, тестовая сборка Preview и lint прошли. Android-тесты прошли на двух эмуляторах, 109 на Android 6 и 111 на Android 16. Для каждого варианта JVM выполнено 423 тестов с одним прежним пропуском. Прогон на физическом телефоне и установка обновления остаются непроверенными.

Изменены `MainActivity.kt`, `AbSearchRows.kt` и новый компонент `AbSearchFilterDialog.kt`. Проверки включают сохранение порядка томов, удаление неподходящей озвучки из выбора и идентификацию скачанного издания по ссылке источника. Результаты сохранены в [JSON](quality/search-filters/results.json).
