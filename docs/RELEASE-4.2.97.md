# Audiobook Preview 4.2.97

Выпуск одобрен пользователем для встроенного обновления и опубликован через GitHub Releases. [Открыть выпуск](https://github.com/smoc1983-web/AudioBook/releases/tag/preview-v100097).

Выпущен исходный подписанный APK из проверенной сборки 44320951915, с хешем и размером прежнего кандидата. Android 16 принял файл поверх 4.2.95 и 4.2.96 с сохранением тестовых данных. Код встроенной проверки обновлений обеих версий нашёл 4.2.97 без входа в GitHub, скачал APK целиком и совпал с кандидатом побайтно. Проверка публикации прошла в [CI](https://github.com/smoc1983-web/AudioBook/actions/runs/44324986263).

Для установки откройте меню обновлений Audiobook Preview, проверьте обновления, скачайте выпуск и подтвердите установку в Android. Если уже установлена тестовая 4.2.97, она совпадает с опубликованным APK. На физическом телефоне установка и внешний вид анимации пока не проверены.
