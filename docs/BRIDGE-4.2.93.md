## Как переключается источник

Старое приложение не умеет менять встроенный origin удалённой настройкой.
HTTP redirect старого JSON на GitHub тоже не подходит: старый updater разрешает
только прежний origin. Нужен один подписанный переходный APK:

1. Тот же файл размещается двумя способами: в старом Site multipart-формате и
   полным APK в GitHub Release `preview-v100093`.
2. Старый Site feed `/updates/preview-update.json` должен предложить код 100093
   по прежнему адресу; части APK остаются на том же origin под `/updates/parts/`.
3. Пользователь скачивает обновление через обычное меню, Android подтверждает
   замену с тем же package и подписью. Удаления приложения нет.
4. Установленный 100093 использует GitHub Releases API для следующих обновлений.

Это доставка одного Preview APK из двух источников, не смешивание Preview/stable.
Для версий, уже обращающихся к GitHub, тот же кандидат предлагается непосредственно
из GitHub Release после отдельной согласованной публикации.
