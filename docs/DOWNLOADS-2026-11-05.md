# Загрузки: этап 6, без публикации

Коллекция сохраняет кнопку «Скачать всю коллекцию». Теперь можно выбрать книги
или раскрыть «Отдельные главы». Показаны сумма известных размеров, число глав
с неизвестным размером и свободное место. Это оценка: источник может не сообщать
полный размер. Подтверждённые демо и HLS/DASH не скачиваются как обычный MP3.

Очередь сохраняет исходную идентичность задания отдельно от обновлённой ссылки.
При HTTP 403/410 допускается одна попытка получить новую ссылку той же главы
из поддерживаемого KB/App/XSPlayer. Сохраняются HTTPS-хост, путь файла и параметры,
определяющие издание/главу; менять можно только известные параметры подписи
медиафайла. Произвольные endpoint/token и чужие файлы не принимаются.
Внешние плейлисты и страницы с проверкой браузера требуют ручного открытия.

Удаляется только принадлежащее этому заданию неудачное задание DownloadManager,
с проверкой ID, владельца назначения, адреса и заголовка. Успешный или чужой файл
не удаляется. После потери локального checkpoint уже принятое Android задание
подхватывается; повторное нажатие не создаёт дубликат. Готовое аудио, прогресс,
закладки и коллекции сохраняются. Разбор очереди проверяет обновлённый URL
относительно исходного. Обработка pump сериализована отдельным Mutex.
