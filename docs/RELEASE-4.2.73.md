# Audiobook4.2.73 — продолжения прямо в коллекции

В карточке книги нажмите «Продолжения»: список раскрывается в этой же коллекции,
не переключая плеер. Видны локальные совпадения по названию (отдельно, без ложной
сверки), сохранённые книги аудиоисточника и каталог Литрес/Author.Today с текстом,
аудио, номерами томов и статусами. Чужие seed/автор/подтверждённый цикл исключены;
выключение уведомлений не скрывает просмотр сведений. Обращения к справочникам
начинаются только при раскрытии. Длинные списки показаны порциями.

Все книги полки доступны через LazyRow вместо ограничения первыми5. Коллекция
имеет меню «⋮» с подписанными действиями открыть/переименовать/удалить. Удаление
полки сохраняет аудио. Основные действия книги — слушать, скачать, добавить в
коллекцию, удалить файлы с подтверждением; избранное/очередь/справочные сведения
в «Другие действия». Перенос коллекций и настройки уведомлений — в «⋮» шапки.
