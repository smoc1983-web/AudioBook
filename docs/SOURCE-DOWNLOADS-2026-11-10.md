# Скачивание из источников внутри приложения, 2026-11-10

Задача выполняется без ub-mode по явному выбору владельца. База — опубликованная
4.2.94 и очистка b091b13. Рабочая ветка cloud/recovery-source-downloads-20261110.
Новый релиз не опубликован; номер версии, пакет и ключ подписи не менялись.

## Изменения

- Audioknigi.top перенесён из ссылок во встроенный поиск (opt-in, сохранённые
  настройки источников не меняются). Извлекается штатный audio_signed_playlist,
  проверяются HTTPS, источник, путь API, числовой id и совпадение newsid ответа.
  JSON-фрагменты title/file разбираются как данные, без выполнения кода;
  повреждённый хвост отклоняется. Порядок глав сохранён, повторы исключены.
  Текущий audio-элемент не подменяет полный список глав.
- Для остальных 13 ранее добавленных адаптеров кнопка «Открыть сайт» заменена
  на «Найти и скачать»: выбор поиска в приложении, скачивание из меню книги.
- Для СлушКинВсем, Aume, Lis10book, Audio-Lib, КнигиAudio и Author.Today
  добавлено явное встроенное окно просмотра. Пользователь открывает книгу,
  нажимает «Проверить главы» и получает существующие элементы выбора скачивания:
  число глав, оценку размера, все/отдельные главы и защиту от известных демо/HLS.
  Используется уже открытая страница, без активации плеера приложения и повторной
  загрузки страницы. Навигация отменяет старую проверку; закрытие освобождает WebView.
- Эти шесть сайтов НЕ объявлены полноценными адаптерами общего поиска.
  Поддержаны явные списки PlayerJS/JWPlayer/DOM/JSON/iframe API, уже используемые
  приложением; одиночный audio-элемент на таких страницах не принимается за книгу.
  При недоступном/неподдержанном списке показывается отказ, файлы не создаются.
- Встроенное окно допускает только HTTPS и точный исходный домен (включая www),
  блокирует внешние переходы, ошибки TLS, file/content-доступ, смешанный контент.
  JS-мост к Android не добавлялся. Автовоспроизведение сайта требует действия.

## Проверка сети (не проверка на телефоне)

- Audioknigi.top: живой каталог, форма поиска, страница «Я тебя отпускаю», API
  вернул одну аудиоглаву; Range-запрос получил 206, audio/mpeg и 4096 байт.
  Подписанные временные URL/сеансовые данные в репозиторий не сохранены.
- Lis10book и Audio-Lib: каталог иногда открылся в Chromium после обычной проверки
  соединения. Переход к книге нестабилен/тайм-аут; полнота скачивания не подтверждена.
- СлушКинВсем: HTTP503; браузер также показывал страницу непривязанного домена.
- Aume: HTTP503/пустая страница. КнигиAudio: ошибка соединения.
- Author.Today: главная доступна. Аудиокнига из аккаунта/платное издание не проверялись.

Не обещать, что все книги всех сайтов скачиваются. Новый встроенный просмотр
не устраняет серверные ошибки, платный доступ или неподдержанный формат плеера.
Автоматическое восстановление истёкших ссылок этих новых форматов не добавлялось:
нужна повторная проверка страницы. Предыдущие механизмы обновления ссылок сохранены.

## Проверки

- `tools/run_checks.py`: успешно, 15 JS-файлов тестов, включая 12 новых проверок,
  индекс 40000 операций и 22 правила восстановления.
- Chromium: 6 проверок явных плейлистов на изолированных HTML-образцах и отказ
  от одиночного audio-фрагмента. Это тест парсера, не утверждение о работе сайтов.
- Stable Debug: компиляция Kotlin/Java, `testDebugUnitTest` (257, 0 ошибок,
  1 прежний пропуск), `compileDebugAndroidTestKotlin`, `lintDebug` — успешно.
- Lint: 0 ошибок, 77 предупреждений, 76 информационных замечаний. Новое
  SetJavaScriptEnabled относится к необходимому JS плееров во встроенном окне:
  точные HTTPS-хосты, запрет file/content и отсутствие Android JS bridge сохранены.
  Новое информационное AutoboxingStateCreation относится к счётчику навигации.
- Первая компиляция нового окна выявила отсутствующий импорт rememberCoroutineScope;
  исправлен, финальный запуск успешен. Попытка assembleDebug прервана после этой
  ошибки; финальная проверка — компиляция, unit и lint, без сборки нового APK.
- Release, Preview и Android instrumentation для этой доработки не запускались.
- TOP отклоняет перенаправления API, чтобы ответ нельзя было подменить списком
  другой книги или другого источника.
Полной загрузки книги и установки на физическом Android-устройстве не выполняли.
