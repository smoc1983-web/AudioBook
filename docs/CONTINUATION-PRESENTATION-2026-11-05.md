# Последний том и диагностика: этап 10

Уведомления сгруппированы по подтверждённой серии, автору и формату. Среди
нумерованных продолжений показывается старший найденный том; текст и аудио
отдельно. Старое запоздавшее обнаружение не поднимается поверх уже прочитанного
более позднего тома. Если номера нет, применяется устойчивый порядок обнаружения,
который не объявляется датой публикации. Неизвестный автор/серия не объединяются
между разными книгами коллекции. Неизвестный формат не создаёт уведомление.

Номер из подтверждённых данных сохраняется в inbox/available; старые записи
читаются без него с прежним форматом. Полная история остаётся на устройстве;
в настройках доступна кнопка всех найденных томов. В карточке указаны формат,
номер/неизвестный порядок, известный источник и время обнаружения. В официальной
сверке раздельно показаны последняя попытка и успешная сверка: ошибка не делает
старый сохранённый каталог свежим. Ошибки DNS/таймаута/подключения объясняются
по-русски; адреса из произвольных сообщений исключены.

Сохранены привязка только к коллекциям, отключение/приглушение, независимые
опции текста и Литрес, тихая первая полная сверка, запрет оповещений по
неполным спискам/анонсам/конфликтам порядка, повторная проверка коллекции
после сетевого запроса. Общая лента новинок Литрес не включается.
Старые системные уведомления о предыдущих томах снимаются при появлении нового,
уведомление плеера не затрагивается.

TDD: 3 ожидаемых отказа из 5 на заглушке. После реализации 7 JVM-тестов прошли,
включая разные форматы/авторов/серии, прочитанный старший том, историю,
устойчивость порядка, JSON и понятные ошибки без URL. Полный локальный unit,
AndroidTest Kotlin/Java compile и lint прошли. Kotlin не поддержан Java-метриками.

Native добавлен для настоящего NotificationManager: только старший аудиотом и
текстовый том собранной серии, посторонний seed не уведомляет, удаление коллекции
снимает уведомления без удаления истории; UI показывает формат/номер/источник/дату.
В полный набор включены прежние OfficialSeriesTest и ContinuationWorkerTest,
в том числе удаление книги во время запроса и тихий baseline. Финальный CI пока
не выполнен. Физического теста нет. Новый выпуск не опубликован.
