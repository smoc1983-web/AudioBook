# Скачивание из контекстного меню — журнал разработки

2026-10-29: пользователь разрешил ub-mode для этой задачи. В дальнейшем перед
каждой разработкой спрашивать о выборе процесса. Исходная версия70 не меняется
во время разработки. Рабочая ветка feature/menu-download-edition.

## Поведение и решения

- Причина: AbBookMenu имело только открытие книги; список глав получал экран книги.
- Добавлен отдельный сеанс существующего AbOpenPageTask в меню. Он повторно
  использует проверку источника, тайм-аут и закрытие WebView. Не пишет состояние
  выбранной книги, навигацию и PlaybackService. Закрытие меню отменяет чтение.
- После проверки издания показаны число доступных глав и размер аудиофайлов.
  Использован существующий ограниченный HEAD/Range-проверщик AbAudioSizes.
  Полное тело аудио для подсчёта размера не скачивается. Частичный объём не
  считается полным; неизвестные заголовки не превращаются в нулевой размер.
- Новое действие использует существующую очередь requestModernDownload и индекс
  скачанных глав. Записывает URL, обложку и общее число глав только при скачивании;
  текущую книгу и звук не переключает. Недостающие главы можно дозагрузить.
- Доказанные ознакомительные фрагменты (метка названия или /get_mp3_trial/ в
  пути аудио) заблокированы. Количество глав и размер сами по себе не доказывают
  полноту: короткий рассказ может состоять из одного файла. Остальные издания
  имеют явное предупреждение, что полнота источником не подтверждена.
- Нет ссылки/глав или ошибка сайта: загрузка не начинается, есть причина и повтор.
  Размер онлайн-издания не подменяется объёмом локальной частично скачанной книги.

## Проверки

1. До реализации EditionDownloadRules четыре JVM-теста дали две ожидаемые ошибки:
   игнорировались явная метка фрагмента и trial-путь. После реализации 4/4 прошли.
2. Добавлены Android-тесты настоящих контролов меню: число глав/известный объём,
   callback загрузки без изменения PlaybackService, блокировка фрагмента,
   дозагрузка/полная локальная книга и частичный размер, разбор данных источника.
3. Отдельный workflow edition-download.yml собирает debug и запускает JVM, lint,
   эти UI-тесты и регрессию области уведомлений на Android23/36. Он не публикует
   выпуск и не использует ключ подписи. Результаты CI пока ожидаются.
4. Crapper/Dryer/Mutator применяются к новому Java-компоненту; Kotlin не поддержан
   закреплёнными инструментами и проверяется реальными Android-тестами.

Внешние источники могут скрыть факт неполноты; гарантия полноты по размеру невозможна.
Физический Samsung/настоящий сетевой источник этой доработкой ещё не проверялись.
