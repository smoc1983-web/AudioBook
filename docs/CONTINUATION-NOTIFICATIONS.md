# Уведомления о продолжениях в коллекциях

Добавлены фоновые проверки новых книг в циклах из пользовательских коллекций.

## Как пользоваться

1. Добавьте книгу в любую коллекцию. Сайт должен указывать её цикл.
2. Откройте **Коллекции → Продолжения книг в коллекциях** или **Настройки → Продолжения**.
3. Уведомления включены по умолчанию. Разрешите уведомления Android, чтобы получать их в шторке. Список новинок доступен в приложении и без этого разрешения.
4. Можно нажать **Проверить сейчас**. Первая успешная проверка запоминает уже опубликованные книги без уведомлений; следующие сообщают о новых подтверждённых продолжениях.

Проверка выполняется примерно раз в 12 часов при подключении к интернету и достаточном заряде. После изменения коллекций первая проверка планируется примерно через минуту. Android может отложить работу. Принудительно остановленное приложение возобновляет фоновые проверки после следующего запуска.

## Достоверность и ограничения

- Проверяются явные ссылки на циклы на исходных сайтах. Названия книг сами по себе не используются для угадывания продолжений.
- Поддержка зависит от доступности публичной страницы цикла и полного списка книг без выполнения JavaScript. Сайты без этих данных отображаются с объяснением; наличие источника в поиске не гарантирует фоновую проверку его циклов.
- Новый том дополнительно проверяется на своей странице: принадлежность циклу, автор, отсутствие анонса и признаки доступного аудио. Сам факт появления страницы книги не считается выходом аудиозаписи. Пронумерованные будущие тома выше номера добавленной книги дополнительно проверяются уже при первой подписке (до 10 самых новых); запись без аудио не помечается вышедшей и будет проверена снова. Это позволяет уведомить о её аудиорелизе, даже если страница появилась до включения функции.
- Разные озвучки одного номера тома не создают повторных оповещений. Повторные проверки используют сохранённые снимки; временные ошибки не заменяют их пустым результатом.
- Первая проверка служит точкой отсчёта, поэтому не сообщает о книгах, опубликованных до её выполнения.
- За один проход: до 16 книг из коллекций по очереди, до 24 HTTP-запросов, 8 МиБ ответов, 6 минут; до 6 страниц и 500 книг на цикл. При достижении лимита оставшиеся книги проверяются в следующих проходах.
- До 100 последних новинок сохраняются в отдельном приватном хранилище приложения. Удаление новинки из списка не сбрасывает снимок цикла. Выключение проверки не удаляет коллекции, скачанные файлы или настройки плеера.
- Переход из системного уведомления открывает сохранённую книгу в приложении без автоматического запуска звука. Внешний URL из Intent не принимается.
- Публичные HTTP-страницы запрашиваются через HTTPS, только для точных доменов текущих источников; переходы на сторонние сайты запрещены. Нет фонового WebView, обхода CAPTCHA, входа в аккаунты или передачи cookies браузера.

## Реализация и проверки

`AbContinuationAlerts` / `SeriesContinuationWorker`: WorkManager, уникальное периодическое задание и ручное задание, общий Mutex, отдельный канал уведомлений. `ContinuationStore`: снимки в приватной папке, отдельные настройки и список новинок. `ContinuationParser`, `ContinuationPolicy`, `ContinuationRules`: чистые Java-классы для проверяемого извлечения и сравнения данных.

Публичная страница Bookinfo `https://bookinfo.net/series/kamennyy-vek-belin` проверена 24.10.2026: получены тома 6, 5, 4, 3. В `app/src/test/resources/continuations/bookinfo-series.html` сохранены только заголовок и карточки этой страницы, без скриптов, cookies и токенов. На странице тома 6 явно указано `audioFiles: []`, поэтому наличие этой страницы не используется как доказательство доступной записи.

14 новых JVM-сценариев проверяют первый снимок, новые тома, повторные озвучки, старые переиздания, авторов, римские номера, реальные карточки Bookinfo, рекомендации, пагинацию, проверку доступа и неполные JS-списки. Инструментальный сценарий запускает настоящий Worker с подменённой сетью: первая проверка, пустой плеер, подтверждённый том, повтор, сбой сайта, восстановление, удаление из коллекции и выключение функции. ## Установка

Стабильный кандидат использует прежний applicationId `com.audiobookdownloader` и библиотеку `Download/AudioBooks`. Он остаётся **неподписанным** до подписания исходным ключом на телефоне с помощью `scripts/sign-phone-update.sh`. Установленную стабильную версию не удалять. Preview устанавливается отдельно и использует отдельную библиотеку.

Готовые файлы: [Preview APK](https://github.com/smoc1983-web/AudioBook/releases/download/preview-v100045/Audiobook-Preview.apk), [архив стабильного кандидата для подписи на телефоне](https://github.com/smoc1983-web/AudioBook/releases/download/preview-v100045/Audiobook-stable-sign-on-phone.zip). Архив содержит исходный скрипт подписи без изменений; ключи в него не входят.

В сборке 45 расширен Android-сценарий: будущий том уже находился в списке в момент первого снимка, затем получил аудио. Уведомление появляется один раз после появления записи. Схема снимка 3 заново создаёт исходное состояние старых снимков из сборки 43; коллекции и скачанные файлы не меняются.
