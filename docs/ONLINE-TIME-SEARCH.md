# Время онлайн-книги и общий поиск

Контрольный запрос пользователя: «сыны грома». Исправления относятся к Audiobook; ForTanya, источники и библиотека не менялись.

## Онлайн-время

Прежний экран показывал оставшееся время только при известных длительностях всех глав. Длительности локальных файлов читались, онлайн-файлов — нет; длительность проигранной онлайн-главы также не сохранялась для последующих расчётов. Сайты, передающие только URL глав, оставались без времени книги.

AbAudioDurations читает метаданные в фоне с двумя рабочими потоками. Для HTTP(S) используется seekable AbDurationRanges: блоки 32 КиБ, максимум 512 КиБ на файл, время чтения ограничено, активное соединение закрывается при отмене. Не происходит предварительного скачивания аудиокниги. При Range-ignoring ответе разрешено прочитать только первый ограниченный блок; переход к полному скачиванию для произвольного смещения запрещён. Cookies/Authorization не пересылаются на другой origin при redirect; проверка HTTPS сохраняется. Формат/длительность извлекает Android MediaMetadataRetriever. Поддерживаются и уже скачанные file/content главы в смешанном онлайн-плейлисте. Данные онлайн-длительности кешируются на устройстве; длительность подготовленной MediaPlayer главы также запоминается.

AbBookTimeRules считает время по текущей позиции и скорости, причём неизвестная длительность уже пройденной главы не мешает точному остатку, когда оставшиеся длительности известны. Неизвестная будущая глава не считается нулевой. До уточнения времени всей книги показан остаток текущей главы и ход определения метаданных; при неудаче доступен повтор. Длинные книги не ограничиваются Int миллисекундами. Дополнены duration/len/length/time поля в разборе страниц.

## Общий поиск

Прежний UnifiedBookSearch создавал один браузер и переходил к следующему сайту после завершения предыдущего. Первой шла карта Азбуки с ожиданием до 90 секунд; это задерживало Bookinfo и все остальные сайты. Теперь AbSearchCoordinator запускает максимум два независимых задания, медленная карта планируется после остальных. Общий и одиночный режим используют один abSearchOneSource с прежними сайтами, формами и парсерами. Ошибка/таймаут одного задания не отменяет остальных. Отмена пользователем и смена запроса закрывают браузеры и не создают ложные сетевые ошибки для старого запроса. Промежуточные результаты сохраняются в выдаче, объединение дубликатов осталось прежним.

Это не гарантирует отсутствие ошибок сторонних сайтов: HTTP-ошибка, проверка браузера или отсутствие книги остаются видимыми для соответствующего источника, а найденные книги с остальных сайтов доступны сразу.

## Реальный контрольный пример

В свежем Chromium с действительной TLS-проверкой выполнены производственные JS-скрипты поиска. Bookinfo вернул «Сыны грома» (иеромонах Симон), 30 глав, ни одной длительности на странице. Ссылки и наблюдение — в docs/verification/live-search-syny-groma.json. Сервер первой главы ответил HTTP 206 с корректным Content-Range; ограниченное чтение 128 КиБ позволило получить метаданные длительности первой главы (485.784 с) внешним ffprobe, не скачивая целый файл размером 5 595 428 байт. Это проверка доступности метаданных реального файла, не подтверждение прослушивания всей книги на телефоне. В Книгоблуд запрос был отправлен штатной формой, но за шесть секунд наблюдения результатов не вернулось; подмены результатов чужими книгами нет.

## Проверки и установка

Финальная сборка 4.2-preview.41 / 100041: https://github.com/smoc1983-web/AudioBook/actions/runs/40124351821 . Все 162 JS-сценария, по 53 JVM-теста для Preview и stable и пять Android-тестов прошли; в каждом JVM-варианте пропущен один необязательный сетевой тест. Android-тесты заняли 41.217 с. Результаты и идентичности — docs/verification/checks-100041.json, preview-100041.json и stable-candidate-100041.json. JVM-тесты проверяют расчёт, неизвестные длительности, диапазоны реального тестового HTTP-сервера, лимиты чтения, перенаправления, изоляцию ошибок, таймауты и отмену поиска. Android-тест использует настоящий native metadata extractor и проверяет сетевые диапазоны, кеш и смешанную локальную главу. Ранее сохранённые тесты запуска, шторки, коллекций, pagecurl, виджетов и виртуального встряхивания остаются включены. Физического Samsung в среде нет.

Стабильный кандидат собирается с прежним com.audiobookdownloader и Download/AudioBooks; для обновления подписывается исходным ключом Code on the Go на телефоне. В архив включён исправленный sign-phone-update-fixed.sh с отдельными паролями PKCS12 и сверкой подтверждённого сертификата. APK/ключ не заменяются случайной подписью. Инструкция — STABLE-INSTALL.md. Установленное приложение не удалять, данные не очищать.

Дополнительно проверены метаданные всех 30 реальных глав Bookinfo: длительности доступны во всех случаях; считано по 128 КиБ на главу, суммарно 3 932 160 байт. Это отдельная проверка ffprobe объявленных MP3 frame-count metadata, не утверждение о воспроизведении всей книги в Android. JSON — verification/live-syny-groma-all-chapter-metadata.json.
