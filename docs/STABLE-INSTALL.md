# Обновление установленной стабильной Audiobook

Стабильная сборка: `com.audiobookdownloader`, прежняя папка `Download/AudioBooks`, прежние SharedPreferences `audiobook_downloader`. Preview остаётся отдельной сборкой. Обновление не очищает данные приложения, настройки и индекс библиотеки; готовые аудиофайлы сохраняются. Прежняя фоновая уборка удаляет только пустые папки и собственные метаданные без аудио, а не скачанные главы. Для существующих виджетов сохранён компонент AudioBookWidget. Каналы обновления stable-v и preview-v разделены; APK чужого канала и чужая подпись отклоняются.

## Исходный ключ Code on the Go обязателен

Установленная пользователем стабильная версия была собрана в Code on the Go на телефоне (уточнение пользователя после первоначального ответа «AIDE»). Её исходный ключ и сертификат в этом репозитории отсутствуют. `Audiobook-stable-UNSIGNED.apk` — подготовленный кандидат, **не установочный APK**. Он намеренно не подписан ключом Preview или случайным debug-ключом. Для обновления нужна та же подпись, что у установленного APK; изменения имени пакета недостаточно.

В прежнем проекте можно выполнить `./gradlew :app:signingReport`: строка Store показывает исходный ключ, Alias — имя ключа, SHA-256 — его сертификат. В Code on the Go обычная debug-сборка Gradle использует ключ `$HOME/.android/debug.keystore`. Если в старом проекте задан signingConfig, нужен указанный там ключ. Сохраните резервную копию исходного keystore и исходного APK. Не удаляйте Code on the Go, его данные или установленную стабильную Audiobook. Не публикуйте keystore и пароли в GitHub или в диагностике.

Можно подписать готовый кандидат **на телефоне**, сохранив ключ в Code on the Go:

```sh
bash sign-phone-update.sh /sdcard/Download/Audiobook-stable-UNSIGNED.apk
```

Скрипт находится в scripts/sign-phone-update.sh и в архиве кандидата. Он читает установленный APK через Android, проверяет пакет и повышение версии, выравнивает и подписывает кандидат исходным ключом, сравнивает SHA-256 сертификатов. Пароль вводится локально. При несовпадении не экспортирует установочный APK и ничего не устанавливает. При запрете чтения установленного APK передайте экспортированную копию вторым аргументом. Для пользовательского ключа задайте AUDIOBOOK_SIGNING_KEYSTORE и AUDIOBOOK_SIGNING_ALIAS. При успешной проверке появится Audiobook-update.apk: открыть его файловым менеджером и выбрать обновление. Библиотека и данные приложения сохраняются Android при обновлении той же подписью.

Сравните сертификат исходного APK и кандидата после подписи:

```sh
apksigner verify --print-certs old-stable.apk
zipalign -p -f 4 Audiobook-stable-UNSIGNED.apk Audiobook-aligned.apk
apksigner sign --ks /private/original-signing.keystore --ks-key-alias ORIGINAL_ALIAS --out Audiobook.apk Audiobook-aligned.apk
apksigner verify --verbose --print-certs Audiobook.apk
```

Пароли apksigner запрашивает интерактивно. SHA-256 сертификатов должны совпадать, versionCode нового APK должен быть больше установленного. Исходный отчёт показывал versionCode 1; кандидат использует 100000 + номер GitHub run. Установить `Audiobook.apk` поверх старой версии, **без удаления**. При несовпадении подписей остановиться; не освобождать пакет удалением приложения. Книги Preview автоматически не перемещаются в стабильную библиотеку.

## Сборка

```sh
gradle :app:assembleRelease -PaudiobookChannel=stable
```

Проверки JS, JVM и Android выполняются на том же исходном коде в канале Preview до подготовки стабильного кандидата. Проверка реального обновления пользовательской установки на сервере не проведена: исходный ключ остаётся на телефоне. Скрипт позволяет проверить подпись и подготовить обновление в Code on the Go без передачи ключа. Неподписанный кандидат не публикуется в канал внутриприложенческих обновлений.
