# Обновление установленной стабильной Audiobook

Стабильная сборка: `com.audiobookdownloader`, прежняя папка `Download/AudioBooks`, прежние SharedPreferences `audiobook_downloader`. Preview остаётся отдельной сборкой. Никакие файлы, настройки, индексы загрузок или папки при первом запуске не удаляются. Для существующих виджетов сохранён компонент AudioBookWidget. Каналы обновления stable-v и preview-v разделены; APK чужого канала и чужая подпись отклоняются.

## Исходный ключ AIDE обязателен

Установленная пользователем стабильная версия была собрана в AIDE на телефоне. Её исходный ключ и сертификат в этом репозитории отсутствуют. `Audiobook-stable-UNSIGNED.apk` — подготовленный кандидат, **не установочный APK**. Он намеренно не подписан ключом Preview или случайным debug-ключом. Для обновления нужна та же подпись, что у установленного APK; изменения имени пакета недостаточно.

В AIDE проверьте настройки подписи / выбранное хранилище ключей исходного проекта. Сохраните резервную копию исходного keystore и исходного APK. Не удаляйте AIDE, его данные или установленную стабильную Audiobook. Путь ключа зависит от версии AIDE и выбранной настройки. Не публикуйте keystore и пароли в GitHub или в диагностике.

Сравните сертификат исходного APK и кандидата после подписи:

```sh
apksigner verify --print-certs old-stable.apk
zipalign -p -f 4 Audiobook-stable-UNSIGNED.apk Audiobook-aligned.apk
apksigner sign --ks /private/original-aide.keystore --ks-key-alias ORIGINAL_ALIAS --out Audiobook.apk Audiobook-aligned.apk
apksigner verify --verbose --print-certs Audiobook.apk
```

Пароли apksigner запрашивает интерактивно. SHA-256 сертификатов должны совпадать, versionCode нового APK должен быть больше установленного. Исходный отчёт показывал versionCode 1; кандидат использует 100000 + номер GitHub run. Установить `Audiobook.apk` поверх старой версии, **без удаления**. При несовпадении подписей остановиться; не освобождать пакет удалением приложения. Книги Preview автоматически не перемещаются в стабильную библиотеку.

## Сборка

```sh
gradle :app:assembleRelease -PaudiobookChannel=stable
```

Проверки JS, JVM и Android выполняются на том же исходном коде в канале Preview до подготовки стабильного кандидата. Проверка реального обновления пользовательской установки пока невозможна без исходного APK и ключа AIDE. Неподписанный кандидат не публикуется в канал внутриприложенческих обновлений.
