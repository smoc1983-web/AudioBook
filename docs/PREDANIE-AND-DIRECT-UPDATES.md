# Предание.ру и три действия обновления

Добавлен четырнадцатый источник: Предание.ру, https://predanie.ru/audio/. Сохранены предыдущие 13 источников, отдельный и общий поиск. При обновлении новый источник однократно добавляется к сохранённому набору; последующее ручное отключение сохраняется.

## Источник

Используются реальная форма `/search?q=…`, карточки `.stroki-card` / `.search-result-card`, категории `/rubric-page/…` и JSON `#audioPlaylistRoot[data-playlist]`. Поиск оставляет аудио и смешанные произведения; чистый текст и видео без аудио не попадают в результаты. Источник передаёт имена глав и длительности в общий онлайн-плеер и загрузчик приложения. Предыдущая библиотека, очередь и коллекции не переносятся и не удаляются.

На странице «Пирамида» Леонида Леонова проверены 163 строки плейлиста, 162 уникальных файла; одна повторная запись удаляется обычной дедупликацией плеера. Первый MP3 отдаёт HTTP 206, Content-Type audio/mpeg и диапазон bytes 0-1023/10991752. Прочитаны только 1024 байта, заголовок MP3 подтверждён. Длительность первой записи — 15:11. Это проверка страницы и доступности файла, а не прослушивание всей книги на физическом телефоне.

Фикстуры содержат только публичные карточки, форму поиска, автора, название и плейлист; формы пожертвований, аккаунты и скрипты страницы не сохранены. `current/tests/test-predanie.cjs` выполняет извлечённые производственные обработчики. Исторический упрощённый DOM в тестах отдельно декодирует сущности атрибута так же, как настоящий браузер.

## Обновление внутри приложения

В нативном экране оставлены три кнопки:

- Проверить обновления.
- Загрузить обновление.
- Установить загруженное обновление.

Поля и кнопки подключения GitHub удалены. Приложение не передаёт GitHub-ключи и не содержит ключей подписи. Описание версии загружается из отдельного read-only HTTPS-канала; файлы собираются из частей в приватном кеше приложения, затем проверяются размеры, SHA-256 каждой части и целого APK, applicationId, versionCode и подпись установленного приложения. Android подтверждает установку и разрешение на неё. Автопроверка при запуске остаётся с суточным интервалом и не мешает плееру.

Канал: https://audiobook-smoc1983-updates.amplecoot2048.chatgpt.site/updates/ . Preview: preview-update.json; stable: stable-update.json. Канал опубликован с публичным доступом через Sites, project_id appgprj_6add1a69b6f481918b5e390c8f413992. Без Authorization и cookies проверены HTTP 200 для обоих JSON и всех пяти частей Preview 48. Собранный файл — 37024328 байт, SHA-256 372429e5b4c6f651baf6df88d4c9b25390053a2c8ca69ac2fd54bc8a2329defd — совпал с CI и локальным APK. Приложению не нужен аккаунт GitHub или ChatGPT. Приватные исходники, книги пользователей и ключи в канале не размещаются.

Для стабильного канала нужны APK, подписанные исходным ключом Code on the Go. Исходный сертификат SHA-256: 020e6c23aad35b45e6ef2ee3ef3326a6ddac731b8491162f0d340848887c9bc7. Сервер не располагает этим ключом. Неподписанный кандидат никогда не предлагается как устанавливаемое обновление. Пока подписанный APK не опубликован, stable-update.json содержит available:false, а приложение сообщает, что подписанный выпуск ещё не опубликован.

`tools/package-public-update.py` проверяет APK через aapt/apksigner, сверяет исходную подпись, разбивает файл на части по 8 МиБ и создаёт метаданные. Чужой, неподписанный APK и замена уже опубликованной версии другим файлом запрещены. Ключи и пароли скрипт не читает. Для следующего выпуска владелец подписывает стабильный APK на телефоне и передаёт готовый APK для публикации; участники получают его через три кнопки без ручного скачивания.

Исходник страницы канала и конфигурация сохранены в hosting/updates; полный рабочий каталог — /workspace/sites/audiobook-updates, project_id скопирован из ответа Sites. Сайт обслуживает только дистрибутивы книги; ForTanya не изменён. Финальные результаты CI и проверка канала записываются в docs/verification/checks-100048.json и direct-update-channel-100048.json. Исходный закрытый GitHub release сохранён для старых клиентов; после каждой успешной сборки выпускатель отдельно проверяет и публикует подписанный APK в публичный канал. Наличие GitHub release само по себе этот канал не обновляет.
