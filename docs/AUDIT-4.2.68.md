## Безопасность: что подтверждено

Два предупреждения OSV — уязвимости зависимости, а не доказательство двух атак на Audiobook.
Cleaner с пользовательским Safelist не используется; XSS этим способом не воспроизведён.
Исходный XML 177829 байт с 6000 вложенными namespace-элементами был принят старой версией,
но в отдельном JVM с heap 48 МиБ **OutOfMemoryError не вызвал**. Новый импорт отклоняет его
обычной ошибкой глубины; это не падение приложения.

Краткое описание OSV XML содержит неточность о 1.23.2: машинный диапазон указывает fixed 1.23.2,
а release notes 1.23.2 содержат исправление #2556. Выбор версии проверен повторным OSV-запросом
и регрессиями, а не только номером в кратком описании.

Источники:
- https://osv.dev/vulnerability/GHSA-65r4-943x-97jj
- https://osv.dev/vulnerability/GHSA-pmhh-3w7g-xqp8

## Журнал проверки

1. Зафиксированы исходная ветка, опубликованный APK/feed и разрешения. Рабочие изменения изолированы.
2. Запущены реальные Crapper/Dryer/Mutator; сохранены красные регрессии до исправления, затем результаты после.
3. Проверены зависимости через OSV и свежая разметка Author.Today/Литрес; исправлены импорт, карточки и baseline уведомлений.
4. Первый зелёный CI разобран по артефактам: найдены скрытые continue-on-error 18 ошибок Lint. Добавлен явный блокирующий gate.
5. Проверены настоящий Android 23 и замена старого release APK. Исправлены API несовместимости и тестовые препятствия: диск эмулятора, File.toPath в тесте, неверное предположение об общем runtime старого APK.
6. Последний первичный Android36 прогон отдельно зафиксировал системный ANR эмулятора до теста установщика (No response to onStartJob); это не выдано за успешную установку. Повтор без изменений продукта успешно прошёл все проверки.
7. Создан отдельный probe без копий приложения и j$-зависимостей, с выравниванием AndroidX с целевым приложением. Это тестовая инфраструктура, а не новый доступ к данным телефона.
8. Сохранены исходники и результаты только в audit-ветке. Основная ветка, публичное приложение и канал обновлений не изменялись.

Промежуточные неуспешные CI и их причины сохранены в verification.json.
Потребность jsoup в Java runtime на API 23 подтверждена падением без него; core library desugaring 2.1.5 сохранён.
Заменённые Map/Stream-вызовы дополнительно работают непосредственно на старом API.

## Перед возможной публикацией

Проверить наличие постоянного Actions secret AUDIOBOOK_PREVIEW_KEYSTORE_BASE64 с существующим
ключом. Прежний recovery artifact/cache — временный запас, а не постоянное секретное хранилище.
Старые копии не удалялись и не скачивались в этом аудите: это могло бы потерять единственную
доступную подпись. Их доступность читателям private-репозитория остаётся риском до переноса
ключа и удаления копий отдельным согласованным действием. Сменой ключа это не исправлять.

Требуется явное разрешение пользователя. Затем применить согласованные исходники к main,
выполнить обычный pipeline с новыми gate, проверить подпись/пакет и только после этого
готовить канал обновлений/ссылку. Не удалять приложение, не очищать библиотеку,
не менять установленную идентичность и не возвращать удалённые привилегированные компоненты.
