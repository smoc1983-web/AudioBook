# Удаление аудиофайлов и скачивание коллекций

Пользователь разрешил ub-mode для обеих доработок 2026-10-30.
Исходная опубликованная версия4.2.71; package/подпись/папки не меняются.

## Проверяемые дефекты и причины

- Дополнительные главы при удалении собирались только как MP3, хотя библиотека
  принимает также M4A/M4B/AAC/OGG/OPUS/WAV/FLAC. Неиндексированные файлы и нулевые
  главы этих форматов оставались.
- После удаления проверялся только исходный список, ошибки очистки sidecar-файлов
  игнорировались. Список мог устареть; частичный сбой ошибочно считался успехом.
- Переданный снимок главы не проверял принадлежность выбранной папке.
- Команда удаления находилась внизу длинного меню и исчезала при local=null.
- Коллекции имели только открытие книги; кнопки скачивания всей коллекции не было.
  Старая активная очередь использует название главы как ключ: книги нельзя
  бездумно отправлять одновременно, когда у них совпадают имена глав.

## Изменения

Удаление доступно в начале меню, в том числе при отсутствующем снимке. При
необходимости библиотека повторно читается на IO. Отменяются собственные загрузки
этой книги; новые загрузки той же книги до завершения удаления запрещены.
Приостанавливается только выбранная книга. Поддерживаемые форматы определяются
существующим LibraryRecoveryRules.isAudio. Есть точная граница папки и запрет
перехода по символьной ссылке главы. Сканируются Audio и Downloads MediaStore и
выбранный SAF-каталог; после попытки список собирается повторно. Неудалённые
известные служебные файлы означают незавершённое удаление, а не успех.
Android может запросить подтверждение либо выбор папки. Чужие документы,
коллекции, закладки, online-ссылки и настройки не удаляются. Автоматического
удаления после прослушивания нет. Пустые общие AudioBooks-каталоги сохраняются.

На экране коллекций доступны «Скачать книги» каждой полки и «Скачать книги из
всех коллекций». Диалог получает издания последовательно, показывает главы и
известный/частичный/неизвестный размер. Одновременно показано не более пяти
карточек, чтобы длинная коллекция не запускала сотни size-probes. После явного
нажатия скачивание идёт по одной книге с ожиданием действующих загрузок, через
существующую очередь. Уже скачанные главы пропускаются. Издания одного файлового
названия дедуплицируются, явно помеченные фрагменты блокируются. Отсутствие метки
фрагмента, число глав и размер не гарантируют полноту издания.
Закрытие останавливает ещё не начатые книги; принятые DownloadManager загрузки
продолжаются. Плеер не переключается. Ошибки не обозначаются как успех.
